# 课时作业（同步练习册）录题配方 —— 来源摘要与本地落地

> 来源：[workbook-recipes.md](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/abf73336c7127156843bee082d95096a4608f59f/references/workbook-recipes.md)、[layout-matrix.md](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/abf73336c7127156843bee082d95096a4608f59f/references/layout-matrix.md)、`constraints.md` 的 D/E/F 段。**这是节选摘要**，不是原文全集；与用户明确要求、代码或服务端事实冲突时以它们为准。
>
> 本地落地：结构判定的主口径在 `references/sync-practice-rules.json`，代码入口 `workflow/sync_practice.py`；版面/选项/空壳/选项连续等硬检查在 `scripts/06-upload/audit_type_layout.py`（本地体检第 8 项，阻断）。本文件只作「题型 → 该建成什么样 → 常见返工点」的速查。

## 一、先定粒度（建错只能人工删草稿重传）

判据是**原卷这个大题是不是一个整体**，不是题号连不连续：

| 原卷形态 | 粒度 | 本仓库落点 |
| --- | --- | --- |
| 每小句各自独立、只有一句提示（单词拼写、完成句子、单项填空、语音辨音） | **逐题 standalone** | `sync-practice-rules.json::type_kind` |
| 共用一段语篇/对话/一张表/一个方框（完形、阅读、任务型、补全对话、选词、短文、教材语篇） | **整题组 group** | 同上 |
| 一个任务下多空且「每词限用一次」（选词填空、音标分类） | **整题组 group** | 同上 |
| 同一张图/同一段材料配多道小题 | **整题组 group**（子题 1–N），不拆成 N 个单元 | `audit_type_layout` D10、`structure_gate` |
| 同一大题的判断/匹配/排序/改错（一题干 + 8 小题） | **整题组 group**（子题 1–8） | 同上 |

> `unit_kind` 建批时定死（A10），`PATCH` 改不了、草稿要人工删。接新册别先问「一单元 = 一道题还是一道大题」。

## 二、逐题型配方（字段写法）

| 题型 | 关键写法 | 常见返工 |
| --- | --- | --- |
| 单词拼写 | 首字母紧贴空档 `The loong … in a______ (古代的)`；答案词原形 | 主题维度不允许；首字母与空档间多空格 |
| 完成句子 | **两行**：中文在上、英文不完整句在下；多空答案用 `;` 分隔；**一词一空**（`went back to` → `______ ______ ______`） | 只放中文；拼成一行；多词答案只给一个空 |
| 单项填空 | 题干原样，选项 `A.…` 保留前缀，A–D 连续 | 个别空只有半角空格要补 `______` |
| 补全对话 | 整段对话放 `material`，**每个空位带题号** `1.______`；单元 `options` A–G；子题空壳 `______` 答案写字母 | 正文缺题号 → 底部整串重复；选项不是 7 条 |
| 语音题（辨音/音标分类） | **每个选项**画线字母包 `<u>`；音标分类词框里单词也画线；不属听力、按题型基准给分 | 光秃秃没画线；误判「无音频依据」 |
| 完形填空 | 材料整篇，空位 `__N__`；子题 stem 写题号 `1.`、恰好 4 个选项，**题号与选项同排**；单元 `options` 留空 | 子题写 `______`（多一个空档）；选项数与题号对不上 |
| 阅读理解 | 材料整篇；**每道子题一个设题角度**；子题 stem 照写设问；4 个选项 | 全挂「细节理解」；小题配图挂错层级 |
| 任务型阅读 | 子题设问保留「（不超过5个词）」；答案多解用 `/`；去掉「（言之有理即可）」中文括注 | 设题角度漏打 |
| 选词填空/短文填空/教材语篇填空 | 材料带号 `__1__`/`1.______`；子题**空壳无选项**；必带 体裁+主题 | 子题重复整句；按完形要求 4 选项（假阳性，C12） |
| 翻译 / 单元话题写作 | 写作板块按块拆：句型训练→翻译/汉翻英；实战演练→书面表达/列中文要点（答案放范文） | 整块塞一题；词汇积累/思维导图当题 |

## 三、原卷提示标记（D27，丢了就返工）

练习册每道题前常有方括号标记，**必须原样进题干/材料**：

| 形态 | 例子 | 放哪儿 |
| --- | --- | --- |
| 来源 | `[2025·甘肃白银改编]`、`[2022·安徽中考]` | 题干最前 |
| 新考法 | `[新考法·图片理解]`、`[新考法·单词回填]` | 该小题题干最前 |
| 主题/栏目 | `[传统文化]`、`[安徽人文]`、`[榜样人物]`、`[情境题]`、`[经典谚语]`、`[熟词生义]` | 逐题→题干最前；大题标题上的→题组单元题干最前 |
| 大题级来源 | `Ⅰ.完形填空[2025·六安月考]` | 单元题干最前（作答指令那行） |

选词/短文/完形这类**逐题标记写在材料句子里**（`1.[2024·江苏镇江]On the train…`），跟句子进 `material` 即可。
检查：`scripts/06-upload/audit_source_marks.py --batch … --source 01_source/正文.txt`（本地体检第 18 项，阻断；补录批加 `--partial`）。

**同题真题（D28）**：练习册整题照搬中考真题时**照录不删**，题干最前加 `[2022·安徽中考]`，`explanation` 写明与库内哪条同题；标记改变内容指纹让查重放行，是**唯一例外**。

## 四、表格材料（最容易返工）

1. 先 `dump_docx_tables.py 原卷.docx --table N` 拿真实网格，再写 `materialBlocks`；**不许按文字样子猜列数**。
2. 合并的标签格是一格（`When/What/Who` 竖排），行间用 `\n`，不拆成多个表头。
3. 表格之外的正文放 `material`（渲染在表格上方），表格内容只放 `materialBlocks`，不两边都抄。
4. 空位只写 `__N__`（前后都留），每格恰好出现一次；单元格插图写 `{{img:…}}`。
5. 材料夹表格（前后都有正文）时整篇写纯文本材料，不拆 blocks（否则表格后正文丢失）。

## 五、「一错就整屏变形」的五个点（本地体检兜底）

1. **补全对话正文缺题号** → 底部重复列题号。`audit_type_layout` 的空壳子题检查兜。
2. **填空类材料已带号、子题又写整句/题号** → 重复。`audit_type_layout` D7/SHELL_SUB 兜。
3. **语音题没写 `<u>`** → 画线消失（`audit_underlines` / `check_underline`，本地为格式提示不阻断）。
4. **完形子题没写题号或选项数/字母不连续** → 题号与选项分家。`audit_type_layout` C11/E20 兜。
5. **图片材料与正文同挂** → 同一段显示两遍。`audit_batch_integrity` / `check_tables` 兜。
