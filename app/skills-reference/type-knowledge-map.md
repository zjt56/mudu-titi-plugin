# 题型 → 知识点维度对照（应显示哪些维度）

> 核对来源：[固定提交的机器维度表](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/78e2cef895a850755422c6d3c97dd73505c49e74/references/type-knowledge-map.json) `by_type` 与[打标说明](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/78e2cef895a850755422c6d3c97dd73505c49e74/references/knowledge-tagging.md)。本页为分层解释，不能把旧 `defaults/hints` 当成允许维度；冲突见 [说明](README.md#来源冲突与本次决定)。
> 机器可读版：本仓库 `references/type-knowledge-map.json`（`workbench/taxonomy.py` 用它判定「越界维度」）。
> **显示规则**：维度根节点（主题、词汇、语法、语音、语用、语篇体裁、设题角度）不写进标签；主题只落叶子。

> **整组题型统一组级落标**：只要是组题的内容（完形填空、语法选择、阅读理解、任务型阅读、读写综合、补全对话、听力信息转换、选词填空整题、短文填空、教材语篇填空、听力短文理解、听力长对话理解），标签一律打在组题级，子题 `knowledge=[]`，不在子题中呈现。其中**阅读理解**的文体须通读全文判断，设题角度虽标在组题级，但具体标签来源于逐小题的问法分析后去重汇总。

## 设题角度分两支（目录 1.1）

- **听力类题型**（短对话/长对话/短文/判断/排序/问答/其他；**不含听力信息转换、听力关键词语选择**）→ `设题角度/听力/`：细节理解、推理判断、人物关系、地点推断、主旨大意
- **阅读类题型**（阅读理解、任务型阅读、读写综合）→ `设题角度/阅读/`：22 项，含细节理解、最佳标题、写作手法等

同一个名字在听力和阅读下各有一份，所以**必须带上级 scope**，不能只写「细节理解」。

## 显示层级说明

| 显示层级 | 含义 | 例 |
| --- | --- | --- |
| 叶子（主题） | 主题只写最后一级叶子 | 信息安全、兴趣爱好 |
| 根以下各级（显示） | 可展示完整祖先链；实际标签只存命中的叶子，不把祖先分别存为标签 | 记叙文 → 故事；词汇辨析 → 动词辨析 |
| 叶子 | 语用只写叶子；完整名称内斜杠保留 | 情景交际、谚语/习语（路径 `语用/谚语/习语`） |
| 阅读子项 | 设题角度用 `设题角度/阅读` 叶子 | 细节理解、推理判断、最佳标题 |

**为什么主题不写两级**：一级主题底下还有子节点，`check_tags.py` 会把它判成「停在父节点」直接失败；库内既有数据也是叶子口径。对照表写的「一级+叶子」按「叶子落地」执行，一级主题只出现在交接单的说明文字里。

**绝对不要**把 `主题`、`词汇`、`语法`、`语音`、`语用`、`语篇体裁`、`设题角度` 这些根节点写进标签。

## 约定

1. 维度名本身不写进标签。
2. 主题写「一级主题 + 最后一级」→ **实际落库只写最后一级叶子**（一级主题是父节点，`check_tags.py` 判非叶子）。
3. 体裁、词汇、语法、语音的“根以下各级”指显示祖先链，提交仍只存目录叶子；语用名称与路径逐字保留。
4. 「答案考点」不是独立根节点，而是该题/空实际考的词汇或语法叶子。映射列出的是允许范围，不要求每题机械凑齐所有维度；完形/语法选择不得把答案考点加到题组。
5. 听力关键词语选择的 `knowledge` 只填 `语音/基本读音` 节点本身，不选子类或词汇标签。原标签、一审、二审共用此规则。答案考点按既有独立字段或派生流程处理。

## 各题型的「允许维度」易错清单

- **完形填空 / 语法选择题组**：只有「语篇体裁、主题」，且只打在组级；子题 knowledge=[]，不给每道小题单独打标签、也不单独判难度等维度。
- **阅读理解**：所有标签（语篇体裁、主题、设题角度/阅读/*）仍打在组题级，子题 `knowledge=[]`；文体须通读全文判断（严禁只看首段或一小段），设题角度须逐小题分析每道小题的问法后去重汇总到组题级。
- **任务型阅读/读写综合/补全对话/听力长对话·短文/短文·教材语篇填空**：只在组级落表中维度，子题 `knowledge=[]`。
- **听力信息转换**：只保留「语篇体裁、主题、答案考点（独立派生）」，不挂设题角度/听力，不从目录选词汇/语法。
- **选词填空**：整题（`group`）只保留答案考点（目录 `knowledge=[]`）；单题（`standalone`）删除主题和语篇体裁，只保留「词汇、语法」。
- **短文/教材语篇填空**：有「语篇体裁、主题、词汇、语法」（不含答案考点）。
- **单词拼写**：只有「词汇、语法、语音」；其中词汇维度只落 `词汇/拼写与词形` 或 `词汇/构词法/*`，**不用 `词汇/词汇辨析/*` 子类**（单词拼写不需要辨析）。
- **完成句子**：只有「词汇、语法」，**必须以空格标准答案反推考点，不得以题干非空已有内容打标**。
- **翻译**：有「词汇、语法、语用」。
- 只有 **阅读理解/任务型阅读/读写综合** 才有 `设题角度/阅读/*`。
