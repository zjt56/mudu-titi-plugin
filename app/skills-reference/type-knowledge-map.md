## 设题角度分两支（目录 1.1）

- **听力类题型**（短对话/长对话/短文/信息转换/判断/排序/问答/其他）→ `设题角度/听力/`：细节理解、推理判断、人物关系、地点推断、主旨大意
- **阅读类题型**（阅读理解、任务型阅读、读写综合）→ `设题角度/阅读/`：22 项，含细节理解、最佳标题、写作手法等

同一个名字在听力和阅读下各有一份，所以**必须带上级 scope**，不能只写「细节理解」。

## 显示层级说明

| 显示层级 | 含义 | 例 |
| --- | --- | --- |
| 叶子（主题） | 主题只写最后一级叶子 | 信息安全、兴趣爱好 |
| 根以下各级（显示） | 可展示完整祖先链；实际标签只存命中的叶子，不把祖先分别存为标签 | 记叙文 → 故事；词汇辨析 → 动词辨析 |
| 叶子 | 语用只写叶子；完整名称内斜杠保留 | 情景交际、谚语/习语（路径 `语用/谚语/习语`） |
| 阅读子项 | 设题角度用 `设题角度/阅读` 叶子 | 细节理解、推理判断、最佳标题 |

**为什么主题不写两级**：一级主题底下还有子节点，`check_tags.py` 会把它判成「停在父节点」直接失败；库内既有数据也是叶子口径。对照表写的「一级+叶子」按「叶子落地」执行，一级主题只出现在交接单的说明文字里。

**绝对不要**把 `主题`、`词汇`、`语法`、`语音`、`语用`、`语篇体裁`、`设题角度` 这些根节点写进标签。

## 约定

1. 维度名本身不写进标签。
2. 主题写「一级主题 + 最后一级」→ **实际落库只写最后一级叶子**（一级主题是父节点，`check_tags.py` 判非叶子）。
3. 体裁、词汇、语法、语音的“根以下各级”指显示祖先链，提交仍只存目录叶子；语用名称与路径逐字保留。
4. 「答案考点」不是独立根节点，而是该题/空实际考的词汇或语法叶子。映射列出的是允许范围，不要求每题机械凑齐所有维度；完形/语法选择不得把答案考点加到题组。
5. 听力关键词语选择是独立主类（27 类之一），打 语音 + 词汇 + 答案考点。

## 各题型的「允许维度」易错清单

- **完形填空 / 语法选择题组**：只有「语篇体裁、主题」，且只打在组级；子题 knowledge=[]，不给每道小题单独打标签、也不单独判难度等维度。
- **阅读理解/任务型阅读/读写综合/补全对话/听力长对话·短文·信息转换/选词·短文·教材语篇填空**：同样只在组级落表中维度，子题 `knowledge=[]`；不给子题单独打标签、不做小题二审。
- **选词/短文/教材语篇填空**：有「语篇体裁、主题、词汇、语法」。
- **单词拼写**：只有「词汇、语法、语音」。
- **完成句子**：只有「词汇、语法」。
- **翻译**：有「词汇、语法、语用」。
- 只有 **阅读理解/任务型阅读/读写综合** 才有 `设题角度/阅读/*`。
