# 录题约束总表（来源摘要与本地决定）

> 来源：[固定提交的约束总表](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/78e2cef895a850755422c6d3c97dd73505c49e74/references/constraints.md)，在线读取到文件末尾（含 C+ 及后置 E29–E33、F 段）。本页为节选摘要，未收录全部条目。
> 来源自称“唯一清单”，但原文内部仍有历史冲突；本页不据此获得覆盖用户要求、代码与服务端事实的权威。来源层级与本次裁决见 [说明](README.md#来源冲突与本次决定)。
> 每行三列：**约束** / **依据**（`服务端`强制 or `口径`编辑 or `实测`踩过的坑）/ **违反后果**。
> “服务端/口径/实测”是来源对依据的分类，并非本次验证结果；编辑规则依本次明确需求与记录的决定执行。
> 本工作流 `docs/constraints.md` 与本页覆盖范围不同；本页不是完整技能源文，也不自动覆盖该文档。

## A. 服务端硬约束（改不了，违反即报错）

| # | 约束 | 依据 | 违反后果 |
| --- | --- | --- | --- |
| A1 | `attachments[].placement` 只能是 `question`/`option`/`answer`/`explanation` | 服务端 | 写 `stem` 等会**静默 400**，图不显示也无明显报错 |
| A2 | 单个单元附件 ≤ 20 个 | 服务端 | 400 |
| A3 | `difficulty` 只能是 `容易`/`适中`/`困难` | 服务端 | 发布阻断 `legacy_difficulty`；筛选标签也按这三个 |
| A4 | `filterMetadata.categories` ⊆ `优选题`/`易错题` | 服务端 | 越界被拒 |
| A5 | `filterMetadata.difficultyValue` 取值 0–1 | 服务端 | 越界被拒 |
| A6 | `question_type` 只能取 27 个主类之一 | 服务端 | `invalid_type` 阻断 |
| A7 | `subtypes` 只能取 `filter-framework.json` 里列出的值 | 服务端 | 按子类筛选查不到该题 |
| A8 | **`group` 必须有 `material`，且有 `subquestions`** | 服务端 `publish_blockers` | `incomplete_group_unit` 阻断发布 |
| A9 | **组题每个子题必须有非空 `stem` 与 `answer`** | 服务端 | `incomplete_group_subquestions` 阻断发布 |
| A10 | **`unit_kind` 在 `POST /api/uploads` 时定死，`PATCH` 改不了** | 服务端 | 建错粒度只能**人工删除草稿后重传** |
| A11 | `standalone` 不应有 `subquestions` | 实测 | 前端按独立题渲染，子题不显示但占数据 |
| A12 | `PATCH` 的 `subquestions`/`attachments`/`filterMetadata`/`materialBlocks` 是**整体替换** | 服务端 | 只传一部分会把其余字段清空 |
| A13 | `PATCH` 的 `subquestions[].textbookMappings.knowledgeIds` 会**重新引入旧标签** | 实测 | 只改题型却复活了旧的说明文标签 |
| A14 | 批次体积 ≤ 2 MB | 服务端 | 413；练习册整册要按单元/课时分批 |
| A15 | 知识点必须落在目录叶子 | 服务端 + 口径 | `非叶子标签` 阻断 |
| A16 | **harness 读不到草稿**：`GET /api/questions/{id}` 对草稿返回 404 | 服务端 | 「先读后改」走不通，PATCH 现状只能取本地批次快照 |
| A17 | 确认/发布/撤稿/删除草稿只能人工 | 服务端 | harness 调用返 403 |
| A18 | **前端资源（`static/app.js`、`styles.css`）会被整站部署整体替换** | 实测 | 改过的 CSS 规则可能在某次发布后消失，改完要复验线上文件 |
| A19 | 确认入库后知识点可能只在 `question_textbook_mappings` 里；`questions.knowledge_ids_json` 只取主映射 | 实测 | 只看 questions 列会误报「空标签」；需合并 mappings 的 knowledge_ids |
| A22 | 知识点必须同时有名称与 id | 实测 | 按知识点筛不到、卡片只有名字没标签 |
| A23 | `source`（卡片顶部来源标签）只写「名称」，不写位置；题号/部分/小节放 `location` | 编辑 | 卡片标签过长且与「原始位置」重复 |

## C. 题型与知识点映射约束

| # | 约束 | 依据 | 违反后果 |
| --- | --- | --- | --- |
| C1 | 题型与子类**不得新增/改名/合并** | 口径 | 筛选体系崩掉 |
| C2 | 主题维度**只写最后一级叶子** | 口径（250 份安徽卷一致） | `非叶子标签` 阻断 |
| C3 | “根以下各级”用于显示祖先链；提交仍只写目录叶子，语用同样保留完整名称 | 来源 C3 与 A15 的本次解释 | 父节点不能当独立标签提交 |
| C4 | 阅读类设题角度写 `设题角度/阅读/*`，听力类写 `设题角度/听力/*` | 口径 | 标签越界 |
| C5 | 填空拼写类核对实际答案考点（词汇/语法叶子），按组/子题落点，不是新增根维度；完形/语法选择考点写子题 | 来源 C5 与本次分层决定 | 实际考点漏标或错层 |
| C6 | 原文“同维度只挂一个；一题 2–4 个”作为历史精简建议，不设数量硬上限；按题组与子题各自实际范围校验 | 本次明确决定（原文另有 1–3） | 不得据标签数量拒绝合理的多角度题组 |
| C7 | `语音题` 不属于「无音频依据」类，按题型基准 0.72 给分 | 口径 | 被误判「待定」 |
| C8 | 不据词汇/语法/语音的并集给所有题型打标；语音题仅语音、完成句子词汇/语法、拼写词汇/语法/语音，均按实际考点且不挂主题 | 来源概括按 by_type 细化 | 越界维度 |
| C9 | 各题型的允许维度以 `type-knowledge-map.json` 的 `by_type[题型].dims[].branch` 为准 | `check_tags.py` | 越界维度 |
| C10 | 「主题」叶子的父级也占一行，挂之前确认整段路径存在 | 目录 | `知识点路径不存在` |
| C11 | 完形填空：单元 `options` 留空，选项挂各子题；子题必须 4 个选项 | `check_text.py` | 完形选项异常 |
| C12 | 选词填空/短文填空/教材语篇填空：子题**没有选项** | 实测 | 按完形口径要求 4 选项会报假阳性 |
| C13 | 阅读理解：材料图挂单元 `placement=question`；某小题配图挂该子题 | 口径 | 图位置错 |
| C14 | 阅读/任务型/读写综合题组＝体裁＋主题，子题各有阅读角度；短文/选词/教材语篇题组有体裁＋主题，词汇/语法按实际空位；完形/语法选择题组仅体裁＋主题，词汇/语法考点写对应子题 | 来源 C14 括注过宽；结合 by_type 与本次分层决定 | 必带项缺失或考点错层 |
| C15 | **完成句子「一词一空」**：答案是短语/多词时，题干按词数给同样多下划线 | 口径 | 学生不知道填几个词；判卷对不上 |

固定提交的 C+ 仅有 C11–C15（顺序有交错），并无 C21–C26；不可引用不存在的编号证明后续规则。原 C14 把完形与其他填空并列后加“词汇/语法/答案考点”，与 C9、机器表和打标说明组级限制冲突，本次按上表分层执行。

| E23 | 阅读材料正文里夹的插图写成单独一行 `{{img:…}}` | 实测 | 材料插图不显示 |

| E25 | **书面表达题干不写下划线占位**；答题线由前端补丁画 | 口径 | 写作区错位、表格被拆 |
| E26 | **批次完整性四条**：选项 A→… 连续条数对；相邻单元材料不得互相包含；不留 `[来源:…]`/水印；听力组题 material 带「听力原文：」 | 实测 | 选项缺一半、一题两篇、发布才被打回 |
| E27 | **材料里夹表格（前后还有正文）时整篇写成纯文本材料**，不拆 blocks | 实测 | 表格后面正文整段消失 |
| E28 | **表格只放 `materialBlocks`，不要同一张表再抄进 `material`** | 实测 | 同一张表显示两次 |
| E29 | **材料里的加粗/黑体必须保留**（用 `**词**` 标记） | 实测 | 带加粗的题做不出来 |

## F. 内容真实性

| # | 约束 | 依据 | 违反后果 |
| --- | --- | --- | --- |
| F1 | **答案以原卷/答案册为准**；确实没有 → 自己作答并按 F5 标注 | 口径 | 缺答案没法入库；自补未标注会被当成出版社答案 |
| F2 | 解析：原卷/答案册有就逐字录入；没有就必须自己写，末尾标注（F5） | 口径 | 解析成片留空 |
| F3 | 文章大意：有【文章大意】就录原话，没有就自己生成（阅读类必填，2–3 句中文），末尾标注 | 口径 | 阅读卡片没有文章大意 |
| F4 | 主观题答案保留原句，多解用 `/` 分隔；中文括注去掉 | 口径 | `check_answers` 判写法不同 |
| F5 | **AI 生成内容必须在末尾标注 `（AI生成，待校对）`**；答案字段只写答案本身，标记写进 `explanation` | 口径 | 编辑无法区分哪些要校对 |
| F6 | **听力类题型不写内容解析**；答案自补的 explanation 只写一行 `答案由AI生成（AI生成，待校对）` | 口径 | 听力解析容易编错 |
| F7 | **三个缺口一律补齐**：答案、解析、文章大意，缺哪个补哪个，补了就标注；不许留空/占位 | 口径 | 题库里成片空心题 |
