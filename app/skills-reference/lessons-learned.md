# 录题经验教训（踩坑台账·精编）

> 来源：[固定提交的 ISSUES](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/78e2cef895a850755422c6d3c97dd73505c49e74/.learnings/ISSUES.md)、[IMPROVEMENTS](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/78e2cef895a850755422c6d3c97dd73505c49e74/.learnings/IMPROVEMENTS.md)、[CHANGELOG](https://github.com/mudujiaoyu/Mudu-English-Upload/blob/78e2cef895a850755422c6d3c97dd73505c49e74/.learnings/CHANGELOG.md)。本页按主题节选整理，非全部原文；ISSUES 有重复编号，不能用最大编号推算实际条目数。
> 以下现象与处置是来源记录，并非本次复现实测；历史处置可能与后续规则冲突，采用时结合 [来源与裁决](README.md#来源冲突与本次决定)。
> 这些是最贵的资产：很多"约束"都是从这些坑里反推出来的。

## 一、听力切分

1. **按静音中点切会把两遍朗读劈开**。现象：19 段只有 11 段首句对得上。根因：每题读两遍、题内也有停顿。处置：用录音里念出的题号当锚点，切完逐段回读首句比对。预防：`cut_audio.py --verify`，判据是逐段首句全对。
2. **锚点连切吞掉下一大题的中文播报**。现象：一段 176s，混进「Ⅱ.长对话理解」中文题头。根因：`--anchors` 语义是"每段起点"，段间夹着 26–36s 中文题头+长空白。处置：按显式起止切（`--ends`），回读首句 9/9 命中。预防：`cut_audio.py` 新增 `--ends`。
3. **卷首试音混进第一题**。现象：开头 1kHz 测试音/反复"Thank you."/中文设备说明被塞进 li-01。处置：`--intro-end` 显式丢弃、`--trim-intro` 只吸死气。
4. **Whisper 时间戳不可靠**。现象：试音是单音，VAD 切成大量极短片段，长空白后时间戳漂移。处置：改用 silencedetect 长静音（≥3s）定骨架，再逐段回读。预防：转写时间戳只用来找题号锚点，不当切点。
5. **整段转写校验白等**。现象：9 段校验 11 分钟。处置：`--verify-seconds N` 只截每段前 N 秒，11 分钟 → 9 秒。
6. **两遍朗读语速不同，别用"两遍时长应接近"判边界**。安徽卷普遍第二遍更快（同题 9.7s vs 4s）。判据只有一条：段首回读是不是本题内容。

## 二、附件与 PATCH（整体覆盖陷阱）

7. **PATCH 附件把已有图片冲掉**。`attachments` 是整体覆盖不是合并。处置：先只读导出再合并提交（`patch_attachments.py --dry-run`）。→ 约束 A12。
8. **PATCH 子题把附件/知识点冲掉、旧标签自己回来**。根因：`subquestions` 整体替换；`prepare_question_knowledge` 读子题 `textbookMappings` 里的旧 knowledgeIds。处置：先读整段带走、只改目标字段、连 knowledgeIds 一起替换。→ 约束 A12/A13，铁律"读快照→只改目标→PATCH→回读校验"。
9. **用过期快照覆盖已修好的值**。先把完形 stem 改成 `1.`，修知识点时又用旧批次快照（还是 `______`）整体回传，把新值盖掉。预防：任何 PATCH 前先用只读库核对当前值。
10. **附件 placement 写错 → 确认静默失败**。写 `"placement":"stem"`，服务端 `normalize_attachments` 只接受 question/option/answer/explanation，抛 ValueError → 400。→ 约束 A1。
11. **附件缺 kind 字段 → invalid_attachment**。服务端要求 `kind ∈ {audio,image}`，合法文字字段是 `label`/`alt`（没有 `caption`）。

## 三、单元粒度与编号（改了基本只能删重传）

12. **单元粒度定错改不了**。补全对话/音标分类本该整题组，却按小题拆了；`unit_kind` PATCH 改不了，harness 删草稿 403，只能请人工删后重传。预防：接新题型/新册前先确认粒度，`check_structure.py` 上传前拦。→ 约束 A10/D2。
13. **编号跟着"题目顺序"走，改结构就撞车**。版式一变，同一个号指代的题就变了（补全对话变成了语音题）。预防：ID 用"大题段位"留余量，改版式一律"删旧+传新"。→ 约束 D7。
14. **组题子题 stem 不要重复材料标号**。材料里已有 `1.______`，子题又写"第1空"，前端显示两个编号。→ 约束 D3。
15. **子题 stem 三写法**：带选项的完形写题号 `1.`；无选项的填空组题（补全对话/选词/短文/教材语篇）写 `______`。→ 约束 D12。
16. **新结构检查误报连续题号**：判定写成"从1开始连续"，但真题子题用全卷题号。改成"升序且连续"（从 nums[0] 起）。教训：任何序号校验先问"从几开始"。

## 四、知识点打标（最容易大面积错）

17. **大面积漏标+标错维度**。2019 只标了单选和阅读子题，听力/完形/补全/拼写/写作全空；还把完形按"语法/辨析"想。根因：没有判断标准、按"出现什么"而非"考什么"标。处置：定七维度+按题型规定主标签与禁标项。→ 见 [knowledge-matching-rules.md](knowledge-matching-rules.md)。
18. **只写大类不下钻到叶子**。63 个单元停在"语音/基本读音""词汇辨析""记叙文"父节点。→ 约束 C2/C3。
19. **只打题组、子题全空**。544 个子题里 297 个没知识点。根因：只做到 `questions.knowledge`，忘了 `subquestions[].knowledge`。处置：阅读按设问判；完形/语法选择逐空判断实际词汇/语法。历史“其余继承组级”不能当作全题型通用规则。预防：`fill_subtags.py --list`。
20. **补标时把题组 id 记错**。2010 题组 id 是"首题号"，照 2018/2019 记忆套就 not_found。预防：补标前先列实际 id。
21. **知识点越界**：完形题组只写语篇体裁+主题，不挂设题角度；实际词汇/语法写对应子题。拼写/完成句子/翻译不挂主题。→ 约束 C9。
22. **知识点"有名字没 ID"**。`knowledge_ids_json` 为 [] 但 `knowledge_json` 有名字，按 ID 筛不到。根因：后端拆成教材行+知识点行，`questions` 列只取主映射。预防：查库合并 mappings 的 knowledge_ids。→ 约束 A19/A22。
23. **自造子类被闸门拦下**。完成句子子类只有固定 6 项，"改为请求句"是自己造的。→ 约束 C1。

## 五、表格还原（返工重灾区）

24. **原卷材料是表格却压成纯文本**，3 列纵向合并的表格丢结构。→ 必须用 `materialBlocks type=table`。约束 E5。
25. **合并的标签格被拆成多个表头**。原卷 `When/What/Who` 竖排在一个格，入库成三个表头+内容错行。→ 约束 E12。
26. **自造列**。按"文字样子"造列，没照 dump 的网格（gridSpan/vMerge）。→ 还原前先 `dump_docx_tables.py`。约束 E11/E18。
27. **表格空位是裸编号没下划线**。`　16　` / `__ 16 __` / `__20`（缺右下划线）都算错，页面看不出空。→ 空位只有一种写法 `__N__`。约束 E14。
28. **同一个条目两个圆点**。`cell.items` 里写了 `●xx`，前端 `<ul><li>` 又加一个圆点。→ items 只放文字。约束 E10。
29. **表格同一份既写 material 文本又放 blocks → 渲染两遍**。→ 表格只放 blocks。约束 E28。
30. **材料夹表格（前后有正文）拆 blocks → 后面正文整段丢失**（前端 blocks||material 只显示表格）。→ 整篇写纯文本材料。约束 E27。
31. **材料导语没进 blocks / 表格列数不齐右侧溢出**。→ E17/E18。

## 六、媒体与图片

32. **图片起点判断错整组错位**。`word/media/` 前面是 logo/二维码，文件名序号≠选项序号。→ 先看首尾两张图肉眼确认。约束 E2。
33. **阅读选项图挂到单元上，前端根本不显示**。选项图要挂 `subquestions[].attachments`（子题对象才被渲染），挂单元 200 无报错但不显示。→ 约束 E1/D13。
34. **小题配图挂错层级被渲染到材料区**。某小题的配图挂该子题；全篇材料图才挂单元。→ 约束 C13/D13。
35. **材料是图却手打成 material**（三份内容要同步维护）。→ 材料是图就直接显示图，material 留空。
36. **媒体引用与本地文件不一致**，拖到上传才 404。→ build 脚本末尾扫 attachments.url 与 media 目录求差集。约束 E4。
37. **画线部分全丢**。原卷画线是 docx 字符格式（`run.underline`），抽纯文本时丢了。→ 用 `dump_underlines.py` 逐 run 取，写成 `<u>…</u>`。约束 E22。
38. **音标分类词表也要画线**（不止辨音选项和划线提问）。→ 约束 E22。
39. **材料里的加粗/黑体丢了**（如"给黑体词排序"题做不了）。→ 用 `**词**` 标记，按答案册核对。约束 E29。
40. **图片材料与正文是同一段话 → 显示两遍**。二选一。→ 约束 E24。

## 七、文本与格式

41. **下划线变成全角空格**（2020 卷题干空白）。→ 统一 `______`，`publish_check` 扫 `U+3000`。约束 B1/B2。
42. **选项前缀不统一**（`A．` vs `A.`）、下划线过短。→ `check_text.py` 12 类规则。
43. **完成句子"中文上行英文下行"数据显示两行、页面一行**。换行只在 `white-space:pre-wrap` 生效，卡片 `.selection-card-stem` 漏了。→ 约束 B10/D15，且发版会冲掉 CSS。
44. **题干被 grid 拆成多行**。卡片题干是 `<button>` + `display:grid`，题干里的内联 `<u>` 被当成独立 grid 项。→ 补丁：题干包 `<div>`。
45. **原卷英文空格成片丢失/专名粘连/私有区字符**。→ `audit_docx_text.py` 先体检，`TEXT_FIX` 精确替换只补空格不改词。约束 G7。
46. **文档里首字母被控制字符吃掉**（`\x07udit`=`audit`）。批量改 md 后要扫控制字符。

## 八、内容真实性（答案/解析/大意）

47. **答案誊写错位**。跨题组边界没逐题核对，19/20 题填反。→ 用独立誊写的答案表逐题比对，不一致数必须为 0。
48. **原卷没有解析被要求补齐**。不同年份资料完整度不同。→ 口径演进：从"留空"→"可生成"→"缺就补并标 `（AI生成，待校对）`"。约束 F2/F5/F7。
49. **听力不写解析**。听力解析价值低易错。→ 答案自补时 explanation 只写一行标记。约束 F6。
50. **解析曾被当成发布硬门槛**（`missing_explanation` 409）。→ 服务器去掉该项，降为提示。

## 九、查重与上传闸门

51. **重复题目被再次上传**。→ `check_duplicates.py`（ID/同年同题号/内容指纹三维度）。约束 F/D28。
52. **内容指纹误判与漏判**。只取题干→通用指令误判；截断 120 字→漏检。→ 指纹改为题干+选项+子题+材料，归一化 <12 字不查、不截断。
53. **"ID 已存在"被当成闸门失败**。→ 分开报 `content_dups`(阻断) 与 `already`(已入库)；整批已入库判"无需再传"。
54. **同一批无法第二次确认（409）**。补数据只能 PATCH 已有草稿，确认前别重复上传同批 id。
55. **上传串行慢**（8.9s）。→ 本地并行 + 查重/预检合并一次 SSH + 媒体并发 Range 校验，降到 2–3.9s。

## 十、确认/发布/服务端坑

56. **上传返回 502**。真凶常是"某线程持未提交写事务"（cleanup 触发 FK 失败、连接泄漏），进程没崩故不重启。→ 判据 `curl /api/health` ≈5.0s + 日志 `database is locked`；502 先查日志真报错。
57. **确认 500 NOT NULL constraint failed: questions.material**。载荷缺字段存成 None。→ 空串/[] 兜底，`preflight_check` 校验 NOT NULL。约束 A22 相关。
58. **同一张图配多道小题被拆成 N 个单元** → 同图重复渲染 N 次。→ 必须合成一个 group。约束 D31。
59. **判断/匹配类小题一小题一单元** → 题号/材料/难度重复。→ 归一个 group。约束 D29。
60. **组题缺 material / 子题 stem 空**。→ 约束 A8/A9，`publish_check` 补齐组题两项校验。
61. **无子类题型带了子类 → 400 invalid_question_subtype**（语音题/短文填空）。本地闸门当时还放过了。→ 约束 E20。

## 十一、单元写作 / 教材目录 / 前端

62. **单元话题写作整块塞成一道题**。→ 按块拆：句型训练→翻译(1201–1299)、实战演练→书面表达(1301–1399，answer 放范文)。约束 D21/D22。
63. **上传成功但"章节目录"是 0 道题**（没挂教材目录）。→ `link_curriculum.py` 挂 `textbookId + curriculum`。约束 D23/D24。
64. **课时跨两个小节只挂父节点** → 按小节点进去是空的。→ 挂多条映射。
65. **章节目录显示 ≥0** 是前端只统计已加载的题，不是没匹配上。
66. **前端修正反复被发版冲掉**（第 4–5 次）。题干置顶/完形同排/隐藏空壳子题/pre-wrap 换行/prose-before-table/`<u>` 放行/正文夹图，都只存在于线上 static，站点发版整份覆盖。→ 做进 `patch_frontend.py` + `run_upload.py` 自动步骤。约束 E9/A18。
67. **补全对话底部多出一串空壳子题**。`omitSubquestions` 正则只认括号形式，不认 `__51__`/`51.`/`　51　`。→ 补丁放宽识别。约束 D25。
68. **卡片上的单元标题行与"材料"小标题都不要**（前端补丁 13，数据不动）。
69. **审核任务一道一道平铺**。→ 按题源分组、按题源合批。约束 E31/E32。
70. **删题要连带清映射/审核条目/组卷条目**，否则留下孤儿和"0 题试卷"。

## 十二、PDF / 多套卷合并 / 无关环境

71. **PDF 无文字层+拼版，靠几何猜栏一直错**。→ 先判拼版、再定栏数（`--cols-per-page` 人工指定），OCR 用 RapidOCR。
72. **多套卷合并答案册抽表题号互相覆盖**。→ `extract_answers.py --year` 按标题切段并**用表格在正文中的行号位置过滤**；判据 `conflicts==0`。约束 G2。
73. **合并卷按年切分连图片串年份**。media 全卷连续编号。→ `extract_docx.py --split-by-year` 按 `[IMG]` 引用把图复制到 by_year。约束 G1。
74. **难度按题型基准分填**，违反"不要根据题型猜造标注"。→ 按可观测特征打分，听力无稿留空入待编辑清单。
75. **难度取值短码 vs 长标签不一致**（易/中/难 vs 容易/适中/困难）。→ 统一长标签。约束 A3。
76. **技能目录被仓库同步覆盖丢改动**。→ 本地是源，写完立刻 `--from-skill` 收回并 commit。
