## 一、四步流程

1. **定维度**：这题在考什么——话题？文体？设问方式？语法点？词义？交际？语音？
2. **定位分支**：主题 / 语音 / 词汇 / 语法 / 语篇体裁 / 设题角度（阅读/听力）/ 语用。
3. **逐级下钻**：父节点只是「初步判断」，只要它有子节点且能判断，就必须选到叶子。
4. **校验**：先分题组与子题，再核对该层的允许维度、必带项及实际考点；名称与路径必须命中目录叶子。历史标签数量建议不作硬上限。

**落库口径**：主题只写最后一级叶子（一级主题是父节点，`check_tags` 会判非叶子）。

## 三、语音（17 点）

| 考什么 | 落点 | 判别 |
| --- | --- | --- |
| 单词读音、音近词辨音 | `语音/基本读音/字母在单词中的基本读音` | 选项是音近/形近词 |
| 字母组合读音（oo、ea、th…） | `语音/基本读音/常见元音字母组合读音`、`辅音字母组合读音` | 选项差异在同一字母组合 |
| 辅音连缀、失爆 | `常见辅音连缀读音`、`失去爆破` | 连读处辨音 |
| 重音 | `语音/重音/单词重音`、`句子重读` | 标重音、强调信息 |
| 连读、弱读 | `语音/意群/连读`、`弱读` | 连读处听辨 |
| 升降调、节奏 | `语音/语调与节奏/语调（升调、降调）`、`节奏` | 判断语气/疑问 |

> 原匹配细则曾建议音近词另挂词汇辨析，但 `by_type` 的语音题只有语音维度。本次按映射执行，只标实际语音叶子，不据旧提示扩充词汇或主题。

## 四、词汇（20 点）

| 触发条件 | 落点 |
| --- | --- |
| 答案需要加前后缀、词性转换、合成 | `词汇/构词法/派生法（前缀、后缀）`／`合成法`／`转化法` |
| 四个选项同词性、词义相近，靠语境选 | `词汇/词汇辨析/<词性>辨析` |
| 答案是多词组合（短语/固定句式） | `词汇/短语与固定搭配/<动词短语/介词短语/形容词短语/名词短语/固定搭配/句型>` |

**单词拼写怎么细分**：看**答案的词性**倒推，落到 `词汇/词汇辨析/<词性>辨析`：

| 答案词性 | 落点 | 例 |
| --- | --- | --- |
| 名词 | `词汇/词汇辨析/名词辨析` | chalk、role、poems、party |
| 形容词 | `词汇/词汇辨析/形容词辨析` | safe、strict、busy、ready |
| 动词 | `词汇/词汇辨析/动词辨析` | invited、carry、adds、cross |
| 副词 | `词汇/词汇辨析/副词辨析` | twice、fast |

需要变形时**再加**语法维度（`名词的数`／`动词的基本形式`）；需要派生时加 `词汇/构词法/派生法`。
不要停在 `词汇` 这个父节点上。

## 五、语法（344 点）

按「空里考什么」定位 H3 大类，再逐级下钻：

| 考点 | 落点前缀 |
| --- | --- |
| 名词单复数、所有格、专有名词 | `语法/名词/…` |
| 动词形式、及物/不及物、系动词、助动词 | `语法/动词/…` |
| 情态动词（can/must/should… 表能力/许可/推测） | `语法/情态动词/<词>/<用法>` |
| 形容词/副词比较级、最高级、位置 | `语法/形容词/…`、`语法/副词/…` |
| 代词（人称/物主/反身/指示/不定/疑问） | `语法/代词/<类>/…` |
| 数词 | `语法/数词/…` |
| 介词（时间/地点/工具/伴随/原因…） | `语法/介词/…` |
| 连词（并列/从属） | `语法/连词/…` |
| 冠词（不定/定/零） | `语法/冠词/…` |
| 句子种类（陈述/疑问/祈使/感叹） | `语法/句子的种类/…` |
| 时态与语态 | `语法/谓语动词的时态和语态/<时态>`、`…/被动语态/<时态>的被动语态` |
| 非谓语 | `语法/动词的非谓语形式/<不定式/ing/ed>` |
| 主从复合句（宾语/定语/状语/主语/表语从句） | `语法/主从复合句/<从句类型>/…` |
| 主谓一致、倒装、省略、强调 | 对应 H3 分类 |

**时态 + 语态双考**按实际考点选目录叶子，如具体时态用法与对应的被动语态叶子；`被动语态` 等父节点不能作为独立标签提交，不机械要求两条。

## 七、设题角度（阅读 22 点 / 听力 5 点，目录 1.1）

> 目录 1.1 把原来的「阅读技能」并进 `设题角度`，并拆成 `设题角度/阅读/*` 与 `设题角度/听力/*` 两支。
> 同一个名字（如「细节理解」）在两边各有一份，**必须带上级 scope**，否则 `check_tags` 拦下。

**阅读**（`设题角度/阅读/*`）：

| 设问方式 | 落点 |
| --- | --- |
| 「According to the text…」「Which is TRUE…」 | `细节理解`（多选式用 `细节多选`） |
| 「We can infer/learn…」 | `推理判断` |
| 「mainly about」「the purpose」 | `主旨大意` |
| 「best title」 | `最佳标题` |
| 指代 it/they/this | `代词指代` |
| 「Where is the text from」「part of a magazine」 | `文章出处` / `文本类型` |
| 段落作用、行文顺序 | `篇章结构` / `文章脉络` |
| 修辞、写作目的 | `写作手法` |
| 猜词、划线词 | `猜测词义` / `词义理解` |
| 划线句含义 | `句意理解` |
| 作者态度 | `观点态度` |
| 七选五/句子回填 | `单词/句子回填` |
| 排序题 | `句子排序` |
| 图表/看图 | `图片理解` |
| 推断后续发展 / 人物情绪变化 | `推断文章后续发展` / `推断人物情绪变化` |
| 开放性设问、跨学科 | `开放性设问`、`跨学科设问` |

**听力**（`设题角度/听力/*`）：细节理解、推理判断、人物关系、地点推断、主旨大意。

| 设问特征 | 设题角度（听力） |
| --- | --- |
| where / which place | 地点推断 |
| who / whose / whom / relationship | 人物关系 |
| why / what can we learn / suggest / infer / mean / think of | 推理判断 |
| main idea / mainly / best title / topic | 主旨大意 |
| 其余（含信息转换空题干、判断、排序） | 细节理解 |

**以组题为准的整组题型（阅读理解、任务型阅读、读写综合等）只在组级落 `设题角度/阅读/*`**，可写组内出现过的全部角度（按次数排序）；子题 `knowledge=[]`，不逐小题打标签、不做小题二审。只有不属于整组题型的独立单题，才按本题实际设问落阅读角度。

## 九、多标签模板

| 题型 | 建议维度组合 |
| --- | --- |
| 单项填空 | 语法点（+ 词汇辨析 / 短语搭配 / 情景交际，按实际） |
| 完形填空 / 语法选择 | 题组仅语篇体裁 + 主题；子题 `knowledge=[]`（整组题型，不逐小题打标签） |
| 阅读理解（题组） | 语篇体裁 + 主题；组级可汇总实际 `设题角度/阅读`；子题 `knowledge=[]` |
| 听力 | 短/长对话按主题 + 听力角度；短文等按映射另有体裁；关键词语选择无角度，按语音/词汇实际考点 |
| 补全对话 | 语用/情景交际 + 语篇体裁 + 主题 |
| 单词拼写 | 词汇 + 语法 + 语音 + 答案考点 |
| 书面表达 | 语篇体裁 + 主题；不采纳旧 hints 中额外语用的建议 |

原文的“同维度只挂一个、总标签 1–3 个”与打标说明的“通常 2–4 个”均作为历史精简建议。本次不设统一数量硬上限；题组可以汇总多个实际设题角度。用户口径（2026-11-05）：整组题型只在组级打标签，子题 `knowledge=[]`，不逐小题打标签、不做小题二审，不能把整组出现的词汇/语法抄到每个子题。主题按材料依据选择，避免冗余。

## 十、分层维度边界（替代旧禁标矩阵）

| 题型/层级 | 边界 |
| --- | --- |
| 完形填空 / 语法选择的题组 | 只允许体裁、主题；不给组级加答案考点或设题角度；子题 `knowledge=[]`（不逐小题打标签） |
| 单项填空 | `主题/*`、`语篇体裁/*` |
| 语法选择子题 | 不单独打标签（整组题型子题 `knowledge=[]`）；不再要求组级“必须有一个语法点” |
| 听力 | 按具体题型映射与层级；信息转换含答案考点，不能用旧“所有听力禁语法”一概否定对应空的实际考点 |
| 单词拼写 | 映射允许词汇、语法、语音及答案考点；仅标本题实际考查项，不要求每项都出现 |
| 整组题型（完形填空、语法选择、阅读理解、任务型阅读、读写综合、补全对话、听力信息转换、选词填空、短文填空、教材语篇填空、听力短文理解、听力长对话理解） | 只在组级落知识点与难度；子题 `knowledge=[]`，不做小题二审 |

## 十一、真踩过的错（摘录自技能 ISSUES）

1. **交际用语标成名词辨析**：2019-031「Well done」→ 应为 `语用/情景交际`。
2. **只写大类**：「名词」「副词」「动词」→ 应到 `名词辨析`／`副词辨析`／`动词辨析`。
3. **停在父节点**：`语音/基本读音`、`词汇辨析`、`记叙文` 都有子节点，必须下钻。
4. **节点名带斜杠**：`固定搭配/句型`、`what/which` 是完整名称，取路径末段会提交失败（409）。
5. **给完形题组挂逐空词汇辨析**：整组题型只在组级打体裁与主题，子题 `knowledge=[]`；不把词汇/语法考点写到子题。
6. **只打了题组、子题全空**：这正是整组题型的正确形态；不再要求子题各挂 `设题角度/阅读`，也不因子题 knowledge 为空判定缺标。
7. **主题挂了一级+叶子**：落库只写叶子；一级主题是父节点，写了会被判非叶子。

| 项 | 含义 | 默认是否失败 |
| --- | --- | --- |
| 空标签 | 没有知识点 | 失败 |
