# 硬约束（影响产出入库的子集）

这篇管"录出来的东西会不会被判废"：只保留与产出 `batch.json`、本地审核直接相关的条目，逐条给编号、规则、后果。上传与后台数据库相关的条目见文末一句说明。

## 怎么读

- 编号沿用源规则的字母段，方便和审核记录对账：`A` 服务端硬约束、`B` 文本格式、`C` 题型与知识点、`C+` 组题结构、`C++` 组题打标、`D` 单元粒度与编号、`E` 媒体、`F` 内容真实性、`G` 输入源。
- "后果"一列写的是**最先出问题的地方**：`本地体检`＝`validate` 阶段报错；`审核台`＝`check_tags` / `check_unit_dims` 报错；`入库`＝服务端拒绝或数据挂不上；`返工`＝要重做切片或重录。
- 源规则里有、但本仓库没有对应实现的，直接写"该项在发布侧执行，本仓库不提供"。

## A 服务端硬约束

| 编号 | 规则 | 后果 |
| --- | --- | --- |
| A3 | `difficulty` 只能是 `容易` / `适中` / `困难` | 入库阻断 `legacy_difficulty` |
| A6 | `question_type` 必须是 27 个固定主类之一 | 入库阻断 `invalid_type` |
| A7 | `subtypes` 只能取该主类目录列出的子类 | 入库阻断 |
| A8 | 题组必须有 `material` 和 `subquestions` | 入库阻断 `incomplete_group_unit` |
| A9 | 题组每个子题必须有非空 `stem` 与 `answer` | 入库阻断 `incomplete_group_subquestions` |
| A10 | `unit_kind` 在上传时定死，事后改不了 | 建错只能删草稿重传，整批返工 |
| A15 | 知识点必须落在目录叶子上 | 入库阻断「非叶子标签」 |
| A17 | 确认、发布、撤稿、删除草稿只能人工 | 自动化做这些一律违规 |
| A22 | 知识点**名称与 id 必须成对**，两种字段名都要给 | 只有名字没有 id：按知识点筛不到、卡片标签挂不住，单题改不回来，只能整批重传或在服务器回补 |

A22 展开：批次里 `knowledgeIds`（驼峰）与 `knowledge_ids`（下划线）两种写法都要写。只写名称时，服务端会认为"知识点没变"而丢弃这次提交；批量接口对自动化调用一律 403。补救只能靠带"试跑/应用/写库"三段式的重连脚本，在服务器上回补——属于发布侧动作，本仓库不提供。

## B 文本格式

| 编号 | 规则 | 后果 |
| --- | --- | --- |
| B1 | 空档统一用 6 个半角下划线 `______` | 本地体检判格式错，整段要改 |
| B2 | 原卷的全角空格空档必须转成 `______` | 前端不显示空位 |
| B3 | 只有半角空格、没有下划线的空，按「题号.」位置补空档 | 答案与空位对不上 |
| B4 | 首字母提示紧贴空档：`c______ (露营)` | 空位断开，判错 |

| B9 | 原卷的来源/年份/传统文化标注原样保留在题干 | 丢标记＝返工 |
| B10 | 需要视觉换行时用真实换行符 `\n`，不写 `<br>` | 预览与前端排版错乱 |
| B11 | 材料里的空档必须带可见下划线，`　51　` 写成 `　__51__　` | 空位不可见，学生无法作答 |

## C 题型与知识点

| 编号 | 规则 | 后果 |
| --- | --- | --- |
| C1 | 题型与子类不得新增、改名、合并 | 入库 `invalid_type` |
| C2 | 「主题」维度只写最后一级叶子 | 审核台 `知识点必须是叶子` |
| C3 | 体裁/词汇/语法/语音写到根以下各级，语用只写叶子 | 同上，且筛不到 |
| C4 | 阅读设题角度写 `设题角度/阅读/*`，听力写 `设题角度/听力/*` | 两边的「细节理解」是两个叶子，写错就挂错维度 |
| C5 | 填空、拼写类另加"答案考点" | 漏了按考点筛不到 |
| C6 | 同一维度只挂一个；一题 2–4 个知识点 | 超量或同维度重复，审核台报错 |
| C7 | 语音题按题型基准评分，不算"无音频依据" | 误判为缺证据 |
| C8 | 真题里的单词拼写/完成句子/语音对照表只允许词汇、语法、语音、答案考点，不挂主题 | 审核台越界报错 |
| C9 | 允许维度以题型框架里该题型的维度分支为准 | 越界由 `check_tags` 报告，`--strict` 下失败 |
| C10 | 「主题」叶子的整段路径必须存在，父级也算一行 | 路径不存在＝`知识点路径不在目录里` |

C9 的边界速记：完形只有体裁+主题；选词/短文/教材语篇填空有体裁+主题+词汇+语法；单词拼写只有词汇+语法+语音；完成句子只有词汇+语法；翻译有词汇+语法+语用；只有阅读、任务型阅读、读写综合有 `设题角度/阅读`。

### H. 听力切段（中文卷必须多语种）

| # | 约束 | 违反后果 |

| H2 | 锚点支持线索词、裸题号（`3.`/`Six,`）、中文（含繁体 `題`、中文数字），并剔除句中假题号 | 切点整体错位 |

| H5 | 正文转写与题号播报转写并行；任一遍失败不拖垮整批 | 墙钟翻倍 |
| H6 | 切段产物通过校验时 `audio` 阶段走确定性快路，不调模型、不重写产物 | 重写导致审核指纹变化、审核作废 |
| H7 | 独立题无题号行时退回「引证唯一落在单元原文」；组题子题不走此退路 | 该单元二审永远无法完成 |

## C++ 组题打标（C21–C26）

| 编号 | 规则 | 后果 |
| --- | --- | --- |
| C21 | 组题标签挂在单元上，不在每个子题重复存同一套 | 标签重复计数，筛选取到整组却指错 |
| C22 | 组级设题角度写组内出现过的全部角度，按出现次数排序 | 只写一个，其余小题按角度筛不到 |
| C23 | 装配时每个子题继承自己那一个设题角度 | 子题全都挂同一个角度＝错标 |
| C24 | 子题不挂"语篇体裁" | 按体裁筛选命中整组，指错小题 |
| C25 | 完形/语法选择的组级只挂体裁+主题；某空考到的词汇叶子挂到那个子题 | 组级挂词汇/语法＝`组级不挂` 报错 |
| C26 | 整组仍守 2–4 个标签、同维度最多一个 | 超量报错 |

单元级标签在看台的落点是 `candidates/units/<unit_id>.json`，字段 `applies_to=unit`、`numbers=[组内全部小题号]`、`inherit_subquestions=true`。单元级标签与子题内容分开校验：标签问题进审核队列，题干/选项/图表问题归前置流程。

## F 内容真实性

| 编号 | 规则 | 后果 |
| --- | --- | --- |
| F1 | 答案以原卷/答案册为准，冲突以原卷为准；没有答案时自己作答，但必须能由原文或选项严格推出 | 答案错＝阻断项 |
| F2 | 解析有就逐字录入；**没有就填「无」，不再使用 AI 生成或自行补写** | 未标注的自撰解析视为编造 |
| F3 | 文章大意有就录原话；**没有就填「无」，不生成** | 未标注的自撰大意视为编造 |
| F4 | 主观题答案保留原句，多解用 `/` 分隔，去掉"言之有理即可"类括注 | 判分口径不清 |
| F5 | 不采用 AI 生成内容；历史带 `（AI生成，待校对）` 的内容按缺失丢弃 | 不校验 AI 标记，不阻断 |
| F6 | 听力类题型不写内容解析，缺失同样填「无」；不编造解析 | 编造解析 |
| F7 | 解析/文章大意是可选字段：有原文就逐字提取，没有就留空或填「无」，**不要求补齐** | 本地体检只统计，不阻断 |

新规则：解析/大意不再是必填校验项。能定位就保留原文；定位不到、为空、或历史 AI 内容都按缺失处理，不阻断上传。

## 发布侧条目

`relink_knowledge_ids` 回补、前端补丁、批量删题、发布与撤稿、上传脚本本身——**都属于发布侧，本仓库不涉及**。仓库里没有这些实现，`upload` 阶段也会被强制阻断。
