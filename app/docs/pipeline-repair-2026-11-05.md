# 录题插件调用与听力修复核验（2026-11-05）

本报告纠正此前仅凭包装脚本提示断言“模型限流”、把时长合理当作切片正确的结论。以下测试使用2014安徽卷“新试卷”，不包含上传或发布。

## 调用链的真实问题

- 原wf-agent只认前2000字节的`Stage: review`，实际分轮提示使用`ROUND: labels/sample`，审核被路由到fast。现在按输入正文之前的真实header识别，审核固定审核profile，不静默降级。
- 原脚本用裸`429`/`QUOTA`子串判定限流，备用调用覆盖首次stderr。历史两次失败分别146.782秒与576.197秒，只记录exit=1；没有保留下来的真实HTTP429证据。不能认定由高并发或持续上游限流导致。
- 每次物理调用现在保存独立stdout/stderr/attempt元数据：实际profile、wall_start/wall_end、monotonic duration、prompt_bytes、退出码、结构化错误类别。推理后无final、认证、格式、上下文变化不冒充429。
- 普通分片虽有线程池，但原来缺permit_parallel，调用仍被排他锁串行。现共享调用锁、独占导入锁，并有双线程barrier+实际flock测试。
- 串并行兼容`review_part_units`/`review_max_units_per_part`；两个独立轮次可以并发。部分失败只补失败目标，成功响应保留。
- 过期pending/partial隔离原字节留证；binding/transaction/receipt/raw response不删除。attempt目录检查软链接和越界，重试用唯一目录。
- 输入改变立即停止重试返回可续跑，不重复花模型调用。补审必须复用原冻结盲审上下文（目录、规则与证据齐全），不得临时读取带标签批次或漏知识点目录。

## 听力根因与最终方案

默认`large-v3-turbo`多语种大模型。旧small或small.en不是该要求。安装失败不降级，READY绑定具体模型。

原ASR曾把跨长静音的第3/4题合成102.884–130.205一个段，对齐词却只到111.8。原程序还按字符长度给中文分配假词时间、用段内空格数索引后面无关时间，并把插值切片标verified。这些都已去除。

最终流程：

1. ffmpeg检测≥3秒真实长静音，以其中点分真实语音区域；短停顿不切开两遍朗读。
2. 同一份已加载模型逐区域转写，局部时间加实际采样offset；保留原始segments/region_id/language。
3. English align禁插值，拒绝CJK/混合中文、越界、重叠、倒序、文本缺失、首尾覆盖明显不足；保留段级时间和诊断。
4. 题号及章节锚点支持裸数字/英文数词/简繁体/中文数字；章节序号不能当题号，公交number two不能当题号。
5. 切点只选真实长静音。粗锚点/缺锚点不能直接verified。仅在完整真实region、来源章节题量和已有题号一致，或完整分组范围/标题唯一对应region时补充`region_proofs`。缺证据继续needs_review，不伪造通过。
6. 缓存绑定音频内容SHA256、模型、VAD、语言、align、regions及worker契约；共享内容寻址转写缓存；切片按来源+边界+输出哈希缓存；原子安装、同内容不重写。
7. 主转写已有全部章节定位就跳过第二次整卷转写。CPU默认4线程、batch2、1份模型；切片可并行。音频阶段不再让代理重写证据。
