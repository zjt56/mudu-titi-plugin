# 录题工作流缺陷与回归约束

本清单记录本轮真实出现的问题，以及工作流必须维护的约束。修复预览不等于修复正式批次，目录合法不等于语义正确，空问题队列不等于审核已完成。

## 先识别来源，再切题

- 从原卷卷头、页眉页脚证据识别来源名称、来源类型、年份、地区；文件名和上传年份只是输入提示，不覆盖原卷证据。
- 去掉 Markdown/HTML 排版标记再识别，例如 `2022**年安徽省初中学业水平考试**` 应识别为 2022、安徽省、中考真题。
- 兼容旧卷名「初中毕业学业考试」「初中毕业生学业考试」等；`2014年安徽省初中毕业学业考试` 应保留完整卷名并识别为中考真题，带「模拟」时仍归中考模拟。上传应保留原文件名，未填写标题时可用原文件名展示，不把改存后的 `source.docx` 或「新试卷」当作来源证据。
- 来源名称保留完整考试名；地区、年级、教材版本没有证据时不得猜测。
- 上传选完文件后自动调用模型识别题源分类（`source_type`：中考真题/中考模拟等）、试卷名、来源、地区、年份，写入 `01_source/metadata.json` 与 manifest 的 `meta`；识别不出的字段留空，不猜测、不填「未提供」、不阻断流程。已有非空值优先保留；模型调用失败只记录原因。可用 `python -m workflow.runner identify-meta --batch-dir <批次>` 重跑，手动可在标签弹窗补填。
- 审核界面「分类」指题源分类（取 `source_type`），不是一个叫「未提供」的占位；选题分类（`categories`）另列。
- 来源字段冲突必须留出具体证据和待复核原因；不得在临时装配脚本中硬编码本张卷子的元数据。

## 切题必须从原卷独立对账

不能仅比较 `sections.questions` 与根据同一列表生成的 `units`。每个结构化单元都必须回查原卷定位：

1. 大题声明的小题数、原卷题号和空位、单元成员、装配后子题清单逐层一致；不得丢题、重题或跨材料归组。
2. 原卷题号行、文章空位编号、作文要点编号是不同概念。例如完形正文中的 `__40__` 不能被当成第 40 题选项已经结束；必须包含第 40 题全部 A–D 选项。
3. 行首 `( )40.`、`40.A...`、分行 A/B 与 C/D 选项都要处理。多行选项/续行不能因为第一个选项出现就截断。
4. 阅读在本组最后一道题的全部选项后结束；下一篇的 A/B 材料标、图片、文章不能并入上一组。反向追溯共享材料时，也不能带入上一组的题目或选项。
5. 长对话按每段对话的真实成员成组，例如“回答第6、7题”和“回答第8至10题”分别生成 6–7 与 8–10 两个单元，不得合并成 6–10，更不得只保留第一段。旧正式批次尚未重装配时，工作台必须按当前原卷重建的明确分组展示待审候选，并分别列全题干、选项；不能继续让旧批次分组覆盖新结构。拆分后的候选不沿用旧整段音频或已审核结论，正式数据仍须重新装配和核验。
6. 表格和对话中的题号空位必须在表格/对话上下文中核对。不能用“没有行首题号”直接判丢题，也不能只查首尾两个空位就宣布全部完整。
7. 英语书面表达没有印刷题号是正常情况：根据原卷上一题题号顺延编号，自动继续，不得仅因缺少印刷数字而阻断或要求人工确认。题干和材料仍须对照原卷；禁止把所有大于最大题号的请求都回退到最后一篇作文。工作台与静态预览必须通过 `source_slice` 读取这一明确章节绑定，不能仅调用 `slice_text(81)` 后将作文显示为空；预览不表示编号疑点已通过。作文保留要点、字数要求、邮件开头结尾，排除文末重复卷名。
   - `QUESTION_NUMBER_INFERRED` 是自动顺延编号的正常情况，不因作文缺少印刷题号而阻断；应以作文前的真实试题编号确定上一题，不能把作文内部的要点编号当作题号。其它独立的题目结构或原文保真问题仍按其自身证据处理。现有实现仅在独立原件证明满足严格条件时自动消除此项，还需要扩展到其他正常顺延情形。
   - 自动结果在闸门报告记录顺延编号的来源与依据，不伪称印刷题号或人工核验。其它结构矛盾和题干不符仍按其自身问题处理，不能借顺延规则放过。
   - 顺延编号不代表核对过页图、版面、题图或听力；独立的 OCR、版面或题干真实性问题不能因此消失。隔离回归为 `python3 -m unittest workflow.test_structure_number_inference workflow.test_structure_gate workflow.test_source_structure workflow.test_structure_closure workflow.test_structure_checks`，不运行真实批次以避免改写其闸门产物。
8. 切片保留作答说明、表格、图片引用、段落和原文画线；大题标题、整卷说明、重复卷名、答案附录与题目正文分开。
   - 独立题补大题标题/导语时，`section_leadin` 只能读取题目切片首行锚点之前的源行，不能把无印刷题号作文的题干、圆点要点、图片、注意事项再当导语补一遍。原文内部真实重复内容必须保留，禁止全局文本去重。回归覆盖原文→`source_slice`→`server.detail.source_preview`→`preview_blocks`，并验证原文和正式批次字节不变（`workflow.test_writing_preview`）。
   - 完形 A/B、阅读各篇文章共用同一大题的作答导语（“阅读下列短文…选出最佳选项”“阅读下面短文…回答问题”）。后一组的来源窗口只含自己的文章，构建时必须按已验证的原始/去噪坐标，把同节标题之后、首篇材料之前的完整公共导语补为该组 `stem`；不得继承含限定题号的组内指令，本组专属导语优先。原文审计必须检出公共导语缺失，预览与上传载荷均须保留，并保留 `A`/`B` 分段标签与材料原文；不得留空，也不得把补入的导语当成自身切片来截断材料。`第一节`/`第二节` 前缀属于分段标记，识别时去掉前缀匹配、原文行按原样保存。没有印该导语的试卷保持为空，不生成文字。回归：`workflow.test_question_draft`。
9. 正式批次的题干/材料/逐题选项必须再次对照确认结构。只修工作台预览不能证明已修复批次数据。
   - Word 表格的 `grid_before/grid_after` 是原卷明确存在的空白网格位置。转换 `materialBlocks` 时用空单元格保留，不能丢掉后再让跨列 Notes 与正文行宽不一致；不猜改 rowspan/colspan。存量恢复只接受唯一绑定源表、旧投影逐项相等、提取摘要匹配原件的情况，通过事务备份、来源审计和格式检查后安装。
   - 最终格式卡点优先读 `07_review/upload-format.json.errors` 并显示错误码、单元及说明；`deferred` 的目录读取/媒体部署要求与 `warnings` 不是本地失败原因。缺损报告才回退格式日志的结构化 errors，不能从日志末尾的延期检查里挑一句“必须”误导重试。

## 结构疑点与非阻断候选

- 同类结构疑点按题目或原文定位分别保留，稳定ID不随同类待办数量变化；相同描述的两处疑点按源行号分别处理，不能误确认另一处。
- 当前原件、正文、结构与确认结构摘要均绑定、结构闸门重新通过后，由自动流程关闭已消除的历史结构待办并保存决定日志；不得继续用旧结构待办阻断后续审核。未通过或证据过期时不能自动关闭，非结构标签冲突不受影响。
- 只在原件、正文、结构与闸门绑定有效，且每个未决项都具有可证明的题号影响范围时，对范围以外的完整单元逐一运行隔离题型候选；单项失败后继续其他候选。候选附原文片段与输入/规则指纹，不写正式阶段产物，不代表审核或放行。影响范围不明的全局问题不能猜测可用单元，整体结论必须保留未解决及原因。
- 唯一末节作文编号待确认且其余结构无冲突时，可凭原件与原文一致性、章节及候选题号绑定定位影响范围；题号顺延仍需独立证明，不把局部候选当做确认。
- 以完整提取文本的答案标题、密集答案索引及评分/录音材料等信号识别疑似答案册误上传；该诊断不代表视觉核验，不得把参考答案、评分要点或听力录音稿误作试题，也不得依据答案补造题干。需真实原卷时保留缺失原因，找到匹配原卷则建立独立批次或经正式输入登记重新处理。
- 隔离候选支持经完整性检查的独立单项填空，以及严格限定为单行、单空、提示明确且来源章节与原件逐行一致的单词拼写题型候选。原文须有唯一题号、明确后续题号或章节边界，确认单元与原文切片一致；单项填空要求题干及 A–D 非空。拼写题只生成题型候选，答案与知识点保留待核；同节其他残题不应阻挡可独立核对的题。含图片、表格、题组或不能验证边界者保留未完成。这些机械检查不证明语法、语义完整或视觉核验。
- 对上述单元可提出题型候选；只有原始TXT中正文与纯逐行题号答案附录均唯一出现且顺序一致，或从同一DOCX原件独立提取并确认正文、答案附录及章节归属一致时，才产生答案候选，并在题型及答案候选齐全后，由子智能体1产出解析与大意候选，再由子智能体2在知识点候选里逐字沿用；来源不明的独立答案正文存在时，不假定原解析缺失。DOCX仅支持明确识别的重复章节标题、答案标题和逐行答案；跨章节重号保留待核。外部答案册、PDF原件、带解析或紧凑格式附录不在此答案候选范围。知识点须为目录合法叶子；解析/大意候选按用户规则「有则逐字匹配、无则填『无』、不生成」产出；所有候选仍需语义复核。
- 按题及阶段分别记录成功、疑点和失败；单项异常不阻止其他单元。原件、正文、附录、结构、目录及规则指纹变化会使本次候选失效；保存后调用 `validate_saved_summary` 只检查所记录指纹新鲜度，不认证内容或授权。外部代理进程不受该模块的操作系统沙箱约束。轮询不能发现两次检查之间完全恢复的瞬态修改。正式装配及两轮审核仍依赖真实输入与审核绑定。

## 版面不确定时走整页复核

原生文字对栏序、表格、题图归属或边界解释不清时，保留疑点并提交原页/PDF 给 OCR 版面识别。Word 必须先渲染为 PDF/页图；识别单张嵌入题图不能冒充核对整页。

OCR 输出只是证据，应保留原件及渲染件摘要、页码、识别文本、版面块、任务 ID 与原始结果。没有坐标就明确没有坐标，不能把原生文字层坐标套到 OCR 文本上。服务/引擎不可用、提交结果未知或识别为空时，保留待复核状态；超时有任务 ID 时续查，不重复上传。

## 标签只能来自结构化目录

- 修改标签提供完整层级目录和搜索，可点选叶子添加、删除；不得仅加载前 200 条就声称完整目录。
- 禁止自由创建知识点；后端同样验证完整叶子路径，不能只在前端禁用自由输入。
- 正式批次知识点名称与 `knowledgeIds`/`knowledge_ids` 必须逐项对应；目录可以确定性回填 ID，缺失不能降级为无关警告。
- 题型、难度、来源在数据中可能使用 `question_type` 和 `filterMetadata`，工作台展示与编辑必须用一致映射，题号旁显示对应题型。

## 独立阶段继续推进

- 自动调度按已有依赖图逐阶段尝试；答案失败仍执行独立音频与题型，音频待复核仍可执行已有答案、题型支持的知识点。依赖未满足的装配等待，不能伪造上游完成。
- 单次调度每阶段最多尝试一次，汇总 `failed_stages` 和 `pending_stages` 并保留首次阻断原因；结构隔离候选不改变正式闸门状态，上传始终走专用人工确认命令。

## 两轮是不同执行与真实判断

- AI 初审/目录校验不能冒充一审、二审全部完成。目录校验只能说明值是否合法，不能说明知识点是否符合该题。
- 一审全量盲判重判标签（含知识点与考点关系）；二审抽样核对的默认分母是抽样单位数（独立单题按题号、整组题型按整组，`ceil(单位数 × 20%)`）。整组题型以整组为一个抽样单位、只做组级核对，不逐小题抽检、不做小题二审。
- 分轮保留绑定当前输入的计划、实际执行记录、覆盖清单、比较判断与原文定位证据。未执行、证据缺失或输入已变化必须记“未完成/需重跑”。
- 只有真实差异、冲突、错误或具体不确定项才进入人工队列；禁止每题自动生成“请人工确认”任务。
- 正常 `ok` 不入人工队列；人工在工作台处理异常并最终决定通过。日常流程无需录入审核人姓名或签名密钥，不得生成虚假的人工核验声明。
- 空队列不能代替分轮审核记录；同一轮重复写成两个文件不能当两轮审核。
- 单题发现不阻断其他题或后续独立审核轮次。两轮均执行后，中文整体报告分别说明执行覆盖、质量结论、未决问题；存在发现不等于审核未执行，也不等于允许放行。
- 模型格式/证据失败自动有限重试，仍失败则保留未完成记录并继续其他可执行轮次；续跑仅补缺轮，不清空真实队列。听力语义判断必须提供并读取完整相关对话转写，不能只据问句/首句判答案冲突，转写也不等于听音核验。

## 删除审核批次后重新录入

工作台应提供本地审核批次删除操作，先明确展示目标与范围并确认。删除使用可恢复归档，清理活动列表及对应本地收件箱引用，允许重新上传；不触碰远端题库。路径越界、软链接逃逸、运行中的批次和不匹配的确认不得删除。测试只使用隔离的临时批次，不删除用户真实试卷。

## 既有批次的处理

旧产物可能仍包含合错的长对话组、丢失选项、串入下一篇材料、缺失知识点 ID，以及未经真实分轮审核生成的 `reviewed` 记录。新代码不应自动为它们背书。重新提取或结构修复必须通过正式 runner/import 路径使下游失效；修分组后需要重做题型、听力映射、知识点、装配及审核，不可直接改台账制造已完成状态。

## 来源字段与原文缺项

- 省份地区写 `filterMetadata.region`，题号/页码/章节定位写 `filterMetadata.location`；装配校验必须与导出任务一致，不能要求把省份写入题号定位。
- 原卷只给答案而没有解析时，`explanation` 统一用「无」；模型省略可选字段、返回空值或空白时由导入入口归一化，不因此反复调用模型。不使用 AI 补写，不覆盖原卷已有解析；真实答案缺失、错配和自撰内容仍检查。
- 文章大意缺失同样归一化为「无」，允许推进，不生成概括、不进入人工必审队列。题型、题量和章节按实际原卷，不能套固定中考模板；无听力单元自动跳过音频阶段。
- 完形、阅读理解、任务型阅读、信息转换、补全对话、教材语篇填空、短文填空、选词填空、听力短文理解、听力长对话理解等以组题为准的题型：
  整组是唯一打标签与审核单位——只在组级落知识点，子题 knowledge=[]，不逐小题打标签、不做小题二审；  一审覆盖组内全部小题，二审整组抽取并只做组级核对（不做逐小题抽查），组题不因子题空知识点产生审核冲突。
- 一审/二审执行状态从绑定有效的真实记录读取，二审标签、理由和原文核对按抽中的小题号展示；未抽中不等于待审，也不等于已做二审。完整轮次续跑仅刷新派生队列，失效的比较发现留档，人工决定和真实内容问题保留。
- 解析/大意补写不能据此断言原文一定没有解析；仍需代理对答案附录逐段核对，防止有原解析却漏提后误标为 AI。

## 听力切段与真实计时（2026-11-05 纠正）

- 默认 `large-v3-turbo` 多语种大模型，安装/缓存失败不退回 small。设置页、CLI、默认配置一致；旧 READY 标记必须匹配模型。
- 先用 ffmpeg ≥3秒长静音中点划出语音区域，再加载一份模型逐区域转写，局部时间加回真实原音频偏移。短停顿可能是两遍朗读间隔，不能切开。
- ASR 真实 segments 不得按文字长度分配假词时间。英语对齐不能把中文段、越界/重叠、首尾覆盖明显不足的压缩词时间标为精确；保留原段及诊断。
- 题号/标题支持中英文、简繁体和中文数字；段内空格不能用空格计数映射时间。章节数字不能当题号，公交 number two 不能当题号。
- 缺锚点或粗锚点仅在真实region、章节题量与已有题号全部一致，或完整分组范围/标题唯一绑定物理region时可补充`region_proofs`证明；否则锚点碰撞、段级粗锚点、微段、非真实静音边界均只保留候选；开始或结束任一边界不可靠，该切片不能自动 verified。文件生成不等于题号归属或听音核验。
- 模型并发受 CPU/内存预算控制，默认1份大模型；不要为并发数字让两份大模型争抢资源。主转写已含全部章节定位就省掉辅助整卷转写。
- 缓存绑定音频内容SHA256、模型、VAD、语言、align模式、真实regions和worker契约；不以文件名/秒级mtime判断。同产物不重写；切片按来源+偏移+输出哈希复用。
- audio已有可信产物走确定性校验；待核产物直接返回 needs_review，不花模型调用让代理重写切片证据。独立题型/知识阶段继续执行，上传闸门不伪造完成。
- 调用路由识别真实 ROUND 与 Stage，审核不能走错fast或静默降级。限流只认结构化上游状态，不根据推理里的429/QUOTA子串；原始每次错误均留存。
- 分片调用用共享执行锁，导入用独占锁。串并行使用同一分片配置、有效pending可续用、过期pending隔离留证，binding/transaction/raw response不删除。
- 记录实际调用起止、锁等待、运行时间、输入字节数；导出到回执包含排队/串行导入，不能当单次模型耗时，不能用同时写回证明实际并行。

## 难度别名与离线测试

- 组题子题的 `difficulty` 与 `filterMetadata.difficulty` 必须同值，上传映射会以 `ALIAS_CONFLICT` 阻断；`assign_meta` 按子题顶层值同步嵌套值，缺失才继承组级判断，不另造新难度。
- 填充阶段产物复用时只允许 `06_batch/` 表现层变化；Word 片段哈希、媒体哈希和全部原始证据必须逐字节一致，并重新通过该阶段校验（`python -m workflow.redeliver --dry-run` 先看是否满足）。
- 测试不得真实调用模型：结构闸门用例用 `WF_STRUCTURE_AI=0` 或对 `structure_ai.auto_classify` 打桩；本机配置了模型路由时，未打桩的用例会真的发起调用、拖慢并占用执行锁。
