# 打标签：四个子智能体

设计图（`英语题库录题流程设计.svg`）把打标签拆成四个并行的子智能体，对应四个独立阶段、四份产物：

| 子智能体 | 阶段 | 负责 | 产物 |
| --- | --- | --- | --- |
| 1 | `explanations` | 解析匹配、文章大意匹配；缺失填「无」，不生成 | `04_knowledge/explanations.json` |
| 2 | `knowledge` | 仅知识点标签匹配，教材匹配暂停 | `04_knowledge/knowledge.json` |
| 3 | `types` | 题型与子类、题目词数、题目内容是否完整 | `03_types/types.json` |
| 4 | `answers` | 答案提取、答案与解析的对应整理、难度判定 | `01_source_ans/answers.json` |

四路都完成后才进入组装；一审全量盲判重判这些标签（含知识点、考点关系与难度），二审按 20% 抽样复核题面/答案/标签与原文的对照：整组题型整组抽取、只做组级核对，其余题型按小题抽。图中「AI审核」统指后面的一审、二审，不是额外的第五个环节。

**执行依赖以 `workflow/contracts.py` 为准**：前置组装先完成题型与 `types` 兼容交接；之后听力、答案、解析、知识点四路独立具备启动条件。解析直接消费已提取的原卷/答案材料，不绑定并行写入的答案产物。知识点只输出标签，文字三路分别验收后由组装合并；听力只阻塞内容审核，不阻塞文字汇总和体检。确定性直抄/切片验收与普通执行共享入口，并行不得绕过零模型快路。

**答案/解析模型调用与局部修复**：本地 CLI 与自动并行入口统一使用 `label_execution`。首次每片最多8个完整单元（阅读/完形题组不拆散），并受输入预算约束；每个单元独立通过现有来源、字段与覆盖校验后保存私有检查点。失败时仅携带失败单元重试，不允许覆盖其它单元。限流/超时不当作内容错误反复重发，已完成的独立分片仍保存。全部单元合并并通过原有整批导入器后才登记阶段完成；未完成结果不交付依赖下游。`retries` 保持原配置，作用范围变为未通过的单元。验收已用结构化诊断证明 `retryable=false` 且 `failure_class=source_binding/validator_fault` 时，该单元保存失败候选和来源证据，停止重复模型调用；独立单元继续。换上下文、重试反馈或新建执行轮次不能绕过同一输入下的确定性拒收。来源/代码变化后先用原候选本地复验，通过后才恢复正常交付；模型错号、错坐标或改写仍可按单元纠正。正式产物尚未生成只说明没有通过验收，须检查候选 `response.json` 和验收错误，不能倒推模型没有产出。

解析可返回带源文件 SHA256、原始行号及可选列范围的 `source_ref`，程序复制文字后照常校验题目归属，见 [source-fragments.md](source-fragments.md)。确定性直抄使用与体检相同的来源标题/边界解析：`[IMG ...]解析[IMG ...]` 与文章大意图标标题同样有效，保留正文及多行续文；题组大意按完整题号集合绑定，不按列表顺序分配。Word 逐字段优先，只有同题/同篇缺失字段才用 PDF/OCR 兜底，同题、同来源身份内逐字相同的重复位置按内容等价验证，保留引用的真实坐标，不按锚点数量误判冲突；跨大题/来源身份不得借同文绑定，真正不同的权威解析或归属不明仍拒绝交付，不选首条蒙混通过。直抄也必须经过任务输入绑定和通用导入器的来源/遗漏检查；证据中的“按题号从 Word 原文直接抄录”不能跳过检查或直接登记完成。提示中只保留一次编号来源文本与必要题面，不重复附整份确认结构/题干及草稿空标签。来源不明的原文与章节证据仍完整保留。检查点绑定来源、规则与模型；解析引用使用整文件摘要，因此来源变化会保守失效相关解析检查点，不能用旧引用冒充当前来源。

## 完整原卷答案的确定性直抄

`answers_direct` 先按整课时/板块/大题序列及当前来源坐标验证完整答案，满足时通过普通任务导出/导入交付，不调用模型。合法无印刷号standalone的Roman附录整串英文词（例如逗号分隔数字词）在完整来源证明下保留一条原样答案；不得拆成虚构小题。任意无号文本、单字母逗号串、空printed_numbers或内部别名本身都不证明归属；partial、错课时、跨大题、真实缺题继续拒绝。

原生工具任务与文件/CLI任务使用不同传输说明：前者通过read_unit/read_source等限定工具读取已供应证据并submit_candidate，后者保留NO tools和单JSON回包约束，两者共享全部内容/来源校验规则。模型流TIMEOUT且未提交候选是执行故障，不是答案或来源验收失败；保留typed timeout、模型/工具最后活动时间及原失败任务，不通过延长预算或原样重试冒充修复。只读回执确认已有候选时仍先复验候选。

**表格编号空位**：汇总后的子题题干为空时，先用当前确认结构、正文窗口、原生表格source_ref与question_id源行重建证明；只有完整材料/表格与全部子题保持原文且每个编号空位唯一时，才认可对应空stem。证明只解决空位存在，不证明选项/材料其它语义布局正确；答案非空、A8、来源完整性和真实审核继续独立执行。任何合流/展示层变化都必须通过同一消费者复验，静态早期候选通过不足以宣称合流后通过。

## 子智能体1：解析与文章大意

**防遗漏规则是代码契约**：`content_rules.RULES` 的“防遗漏交付硬约束”必须进入完整任务、文件协议任务和自动/局部分片提示词；`unit_tasks` 额外强调受影响题号和同一错误码复验。`content_labels.py` 为直抄、source_ref 展开与来源体检提供同源标题语法，禁止再各维护一份导致某入口漏识别。回归直接检查实际构建出的三种任务提示，并验证图标标题引用、错误题号拒绝和已有内容不能以「无」替代。收到遗漏错误仅修定位到的解析/大意，不改答案、题型、知识点或完成状态。书面表达仍保留原例外。

**来源优先级（硬规则）**：`Word 原卷/答案材料` ＞ `随附 PDF/OCR 提取原文` ＞ `空占位`。
- Word 有该题解析/该篇文章大意时，一律逐字用 Word，PDF 不得覆盖、纠正或改写；
- Word 确实没有时，才在 `01_source/materials/attachment_*.txt`（PDF/OCR 提取文本）里定位同一题/同一篇并逐字保留，`evidence` 注明来源文件；
- Word 与 PDF 都没有时，解析/大意填「无」，答案记缺失并给出证据；任何情况都不得生成、改写或跨材料借用。

1. **解析匹配**：按真实题号、章节和材料边界，在原卷正文、附录、答案册中定位该题原解析，逐字保留（去掉「【解析】」等字段标题）并给出定位证据。有原解析时不得替换。
2. **文章大意匹配**：按实际篇章及其所属题号匹配原【文章大意】，逐字保留并记录来源位置；重复的 A/B 篇号不是唯一标识。大意只写组级一份，不在每个子题重复。
3. **缺失处理（用户规则）**：确认已提供来源确实没有该题解析或该篇文章大意时，对应字段一律只填「无」，**直接跳过，不再使用 AI 生成、不补写、不推断、不加任何来源标记**。

边界：非听力题组每个子题各自填（缺失填「无」）；独立题缺失也填「无」；听力不写内容解析，缺失同样填「无」；不得串用其它材料的解析或大意。字段不得留空——缺失必须显式写「无」。

```json
{"items":[{"unit_id":"q-1","explanation":"无",
  "articleSummary":"无","subquestions":[],"evidence":["正文第1题；附录第1题仅给答案，无原解析/原大意"]}]}
```

**书面表达（作文）例外**：书面表达没有确定答案，是作文；可能有范文与写作指导，也可能都没有。只要题目存在即可，**不要求**答案/解析/文章大意逐字绑定，缺失填「无」属正常。若原卷确有【参考范文】/【思路点拨】，逐字保留；无法逐字定位只提示、不阻断。禁止自行撰写范文或讲解充当原文。

## 子智能体2：知识点标签匹配

只打知识点：主类、子类、目录叶子与 ID。

**2026-11-11 用户要求：目前只匹配知识点标签，教材尚未就绪，先暂停教材匹配。** 所有来源（含同步练习与单元测验）都不向任务提供 `textbook_index`，不生成教材位置。旧候选的 `textbook` 由导入器明确省略并记录提示，不校验、不传播、不因它阻断知识点交付。原始候选保留，知识点路径、ID、维度、题号覆盖和行级证据照常严格校验。教材目录及独立查询工具保留，恢复自动匹配须另行明确要求。

**只交付标签，不携带或改写内容**：知识点阶段只输出当前契约允许的知识标签及证据，不输出 `textbook`、`answer`、`explanation`、`articleSummary`。答案与解析由独立阶段验收并在组装时合并；组装刷新知识点时不沿用旧自动教材候选。暂停只针对本地自动 `textbook`，不改既有远端 `textbookMappings` 校验与上传授权边界。

## 子智能体3：题型、词数、内容完整

`type`/`subtypes` 只能取当前目录值；`words` 是该单元自身题干、材料与选项的英文词数；`contentComplete` 在题干与材料不匹配、选项缺失或内容被截断时为 `false`。

## 子智能体4：答案、解析整理、难度

`answers` 逐题号从答案原文提取，不猜不补；`difficulty` 依据可观察特征（长度、句式、选项设计、考查点）判定并给出 `difficultyEvidence`，不得只按题型硬套。

## 校验与流转

导入时依次校验：单元与子题完整覆盖、知识目录叶子与维度、答案沿用、内容归属（`upload_content` 按题号锚点判定可溯源或已标注，跨材料串用直接拦停）、阅读与完形类必须有文章大意、知识点不得改写内容。装配不得改写这些字段。

```bash
python3 -m workflow.agent export --batch-dir workflows/<批次> --stage explanations
python3 -m workflow.agent import --batch-dir workflows/<批次> --task-id <task_id> --result <result.json>
python3 -m workflow.agent run --batch-dir workflows/<批次> --stage explanations
```

来源、规则、答案或题型变化会使旧任务包失效；解析产物变化会使知识点、装配和后续审核失效。生成标注与机器检查只说明来源声明、覆盖和结构符合契约，不代表生成内容已通过真实语义审核。
