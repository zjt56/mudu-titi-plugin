# 媒体：图片、音频与卷面

这篇管"图能不能用、音频怎么切、预览长什么样"：图片体检的五类结论、排除清单、听力切段与回读验收、PDF 提取的边界，以及卷面预览的样式契约。

## 图片体检：五类结论

`workbench/media_audit.py` 给每张图一个 verdict，不按图像内容猜题意。先查显式排除、正文引用及可复验的题目来源归属；没有可靠来源身份时才用首个印刷题号和长宽比作启发式判断。

`scoped-v1` 归属必须来自当前 confirmed 的唯一 unit ID、可信 source span，且窗口坐标有效、stem 在当前清洗正文中唯一存在。group 保留全窗口材料，standalone 只认自有题干；跨单元共用图、过期窗口或未知 basis 不能提升为题目图。

| verdict | 判定条件 | 含义 |
| --- | --- | --- |
| `question` | 被正文引用，且落在题目范围内 | 题目配图，进预览 |
| `header` | 只出现在第一道题之前 | 卷头 / 说明区配图 |
| `banner` | 长宽比 ≥ 5:1 | 像横幅广告，不是题目配图 |
| `unused` | 正文没有 `[IMG]` 引用，也不属于任何小题 | 卷头广告、水印等 |
| `excluded` | 在排除清单里 | 人工确认非题目图，上传时跳过 |

优先级：显式排除 > 未被引用 > 当前已验证的 scoped 题目归属 > 位于首题之前 > 长宽比异常 > 被引用即题目图。题组材料图可位于首个小题号之前，纯图组题可没有印刷小题号；两者不得仅因位置或宽高比被过滤。

`summary` 统计这些计数：`question`、`unused`、`header`、`banner`、`excluded`、`total`、`suspicious`。

### 非题目图不进预览

- `header`、`banner`、`unused` 默认**不进**逐题预览。
- 被人工确认排除的（`excluded`）也不进，且上传时跳过。
- 只有 `question` 进预览；如果一张图实际是题目图却被判成 `unused`，先修正文引用，不要直接改 verdict。

### 排除清单

文件：`workflow/media-exclusions.json`，结构固定：

```json
{
  "excluded": ["卷头-logo.png", "二维码.jpg"],
  "notes": { "卷头-logo.png": "学校 logo，非题目图" }
}
```

- `excluded` 里写原文件名。
- `notes` 写一句人话，方便下一个人复核。
- 文件不存在时按空清单处理，第一次排除时才创建。
- 清单是**人工证据**，不是自动判定结果；加进去要能说出理由。
- 部署前做"批次引用的媒体 vs 本地媒体目录"差集自检，缺图直接阻断。

## 图片挂载：不许跨题

图片挂在哪个层级，决定它在哪道题下面显示，挂错层级前端全不显示：

| 场景 | 挂哪里 |
| --- | --- |
| 独立题的选项图 | 单元 `attachments` |
| 题组的选项图 | `subquestions[].attachments` |
| 题组的材料图 | 单元级，`placement=question` |
| 某个小题的配图 | 该子题的 `attachments` |
| 表格单元格里的插图 | 单元格文本内，用图片引用标记 |

规则：

- 一张图只能属于一道题或一个题组，**不得同时挂到多道题**。
- 选项图张数 = 图片题数 × 选项数；对不上就是漏挂或错挂。
- 页眉 logo、二维码、栏目装饰条、分隔线不算选项图。
- 材料整张是图时，`material` 只写「（材料见附图）」，正文不再重复描述图片内容。
- 图片材料与正文不能是同一段话，二选一；图片理解类保留图。

## 听力切段

切分脚本不在本仓库内；这里只约定产物 `02_audio/audio_map.json` 与验收口径。

### 先分层，再切

用静音检测（`noise=-35dB`、`d=1.2`）把整卷音频的停顿分成三档：

| 停顿时长 | 含义 |
| --- | --- |
| 0.8–2.0 秒 | 题内停顿 |
| 8–15 秒 | 题与题之间 |
| 20–30 秒 | 大题之间 |

### 锚点优先级

1. 录音里念出的题号（最可靠）。
2. 长静音中点（退而求其次）。
3. 中文大题指令（题头可占 15–20 秒，只能兜底）。

转写的时间戳不可信：试音是 1kHz 单音，语音活动检测会抖。做法是用静音表定骨架，再用转写找"题号出现在第几个长静音之后"。

### 参数与编码

| 参数 | 作用 |
| --- | --- |
| `--intro-end` | 丢弃考前试音，必须显式给 |
| `--ends` | 首尾各收一次边界，防吞掉下一题报题号或大段空白 |
| 编码 | 单声道、22050Hz、48kbps |

### 验收

- **回读校验不可跳过**：每段切 20–30 秒转写，与听力稿首句比对，全中才算过。
- 同类单元时长应接近；某段明显偏长 = 吞了下一题的播报。
- 长对话、短文前有 15–25 秒作答准备，锚点取正文起点，不取播报起点。
- 同一题朗读两遍且语速可能不同，**"两遍时长接近"不能当段边界判据**，只看段首回读是否是本题内容。
- 段数 = 听力单元数，不是题数；有试音先切掉。
- 听力稿如果是 AI 听写，`material` 开头写「（本段听力原文为 AI 听写，待校对）」，正文保真检查会自动跳过这一段。

## PDF 提取：只是草稿

只用于**没有文字层**的印刷版 PDF（文本提取返回 0 字）。有文字层直接用文字层，不要 OCR。

产出：

| 文件 | 内容 |
| --- | --- |
| `pageNN/colNN.txt` | 按栏切开的文本 |
| `pageNN.txt` | 按阅读顺序合并的整页文本 |
| `pageNN.items.json` | 题号 → 题干 / 选项 / 图片文件 |
| `media/*.png` | 裁出的图片 |
| `report.json` | 版面与识别报告 |

版面顺序：先按页脚页码切页（`-101-` 这类就是页边界，比找空白列可靠），再在页内定栏数（试卷每页 1 栏，答案册每页 2 栏，正文上方通栏表格 + 下方两栏）。8 开纸常是 A4 拼版，一页可能并排 2 或 3 个版面。

已知限制，必须人工核对：

- 通栏与分栏混排时，单一栏数切不准。
- OCR 有系统性错字：`Ⅰ`/`Ⅱ` 变 `1`/`11`、括号不对称、单词被拆成空格。
- 表格只裁成图片，不还原单元格。
- 页眉页脚、装订边可能漏过滤。
- 选项图与文字同行时，题号归属可能错位，需要看 `items.json` 复核。

**PDF 产出是草稿素材**：题型、知识点、答案仍要人工判、人工打标、人工核对。同级目录有 Word 版时优先用 Word，PDF 只用来校对图片题、表格和跨栏断行。

## 卷面预览样式契约

预览是审核人判断"像不像原卷"的唯一界面，样式规则是契约，不是装饰：

| 项 | 约定 |
| --- | --- |
| 中文字体 | 宋体（`SimSun` / `Songti SC`） |
| 西文字体 | Times New Roman |
| 行距 | 1.9 |
| 字号 | 正文 14.5px |
| 大题标题 | 加粗 |
| 下划线 | `<u>…</u>` 与 `__下划线__` 都还原成下划线 |
| 粗体 | `<b>`、`**粗体**` 还原为粗体 |
| 斜体 | `<i>` 还原为斜体 |
| 题号空位 | 全角空格包住的题号（如 `　31　`）渲染成蓝色下划线空位 |
| 表格 | 保留 1px 边框与表头底色 |
| 图片 | 连续题图并排、缩略图限高、点击打开原图 |
| 题组 | 组内小题用虚线分隔，共享材料只出现一次 |

补充：

- 文字换行必须用真实换行符，样式层不解析 `<br>`。
- 书面表达的答题线由前端画，数据里不写下划线占位。
- 翻译、任务型阅读的答题区同理，不用 `______` 充当答题区。
- 预览只读，任何"在预览里改一下"的动作都不写回批次。

## 图片体检怎么走

1. 先确认正文里的 `[IMG 文件名]` 引用与实际文件一一对应，缺文件直接阻断。
2. 跑体检，拿到每张图的 verdict 与整体 `summary`。
3. 逐个看 `header` / `banner` / `unused`：是卷头杂物就进排除清单，是题目图就补正文引用。
4. 排除清单写进 `workflow/media-exclusions.json`，`notes` 里写清理由。
5. 部署前做"批次引用媒体 vs 本地媒体目录"差集，差集不为空不许上传。

`02_audio/audio_map.json` 的最小结构：

```json
{
  "units": [
    {"unit_id": "L-01", "number": [1, 5], "file": "02_audio/u01.mp3", "start": 0.0, "end": 42.3}
  ]
}
```

段数与听力单元数一致，每个单元的 `number` 区间要和结构里的题号对上。

## 媒体问题速查

| 现象 | 先查什么 |
| --- | --- |
| 题目下面没有图 | 图片挂错层级（单元 vs 子题） |
| 图挂到了别的题下面 | 一张图被挂到多处，或选项图顺序错位 |
| 卷头 logo 出现在预览里 | 正文错误引用了它，或没进排除清单 |
| 表格变成一段文字 | 材料没用 `materialBlocks` 的 `type=table` |
| 表格错列 | 列数没照原卷网格写，或合并单元格被拆开 |
| 听力段吞了相邻题 | 锚点选在播报起点，或没用 `--ends` 收边 |
| 听力段开头有试音 | 没给 `--intro-end` |
| 正文和原件对不上 | 文本层缺陷没修，或修复时改动了词句 |
