# 逐题结构：内容边界与七项核对

这篇管"一道题到底该收哪些内容"：独立题收什么、题组怎么切、表格怎么留、什么必须排除，以及六项结构检查加第 7 项内容范围的判定口径。

## 结构从哪里来

结构只从**原卷**推，不从年份、卷型或经验推。三类证据按优先级用：

1. 大题标题行（`Ⅰ.`、`一、`、`Part A`、`第一节`），记序号、标题、题号区间、分值、有无听力。
2. 题号跳跃处：题号不连续的位置就是大题边界。
3. 没有标题的教辅：用"共用材料 + 一句作答指令"判边界。

题型判定要"标题关键词 + 结构特征"双重匹配。匹配不到，或者两种解释同样合理，**停下来问人**；不允许新增、改名、合并题型。

结构特征速查：

| 特征 | 指向 |
| --- | --- |
| 每题 3 或 4 个选项 | 单项填空 |
| 空数 5 / 10 / 15 | 完形填空 |
| 每篇 3 / 4 / 5 个小问 | 阅读理解 |
| 有共用材料或共用选项 | 题组 |
| 题干带限词数 | 任务型阅读 |
| 首字母 + 汉语提示 | 单词拼写 |
| 中文要点 + 80–100 词 | 书面表达 |

图片题的识别：选项位置只剩 `A.` `B.` `C.` 空壳；选项图张数 = 图片题数 × 选项数，按文档顺序取，起点必须肉眼确认（logo、二维码、整篇海报不算选项图）。

## 独立题收什么

一道独立题是一个单元，字段就是它的内容边界：

| 字段 | 内容 |
| --- | --- |
| `number` | 题号 |
| `stem` | 完整题干与作答指令 |
| `options` | 本题全部选项；填空类为题内空位 |
| `answer` | 答案，并记来源（原卷 / 答案册 / 自补） |
| `attachments` | 本题的图片、图标引用及归属 |

不收进来：相邻题的任何内容、卷头、整卷说明、装饰图。

## 题组收什么

题组（一材多题）由"共享材料 + 组级指令 + 成员小题"组成：

| 部分 | 内容 |
| --- | --- |
| `material` | 共用文字材料；表格材料另给 `materialBlocks` |
| 组级指令 | 写在单元 `stem`，渲染在材料之前 |
| 成员小题 | 每个成员有 `number`、`stem`（或空位）、自己的 `options`（如有） |
| 归属关系 | 成员属于该材料，不允许跨组 |
| 媒体 | 材料图、小题图分别挂到对应层级，并标明归属 |

组级规则：

- 一张图或一段材料下的多道小题，**必须**合成一个 group。
- 同一大题的判断、匹配、排序、改错题归一个 group，不拆成一小题一单元。
- 完形与语法选择的 `options` 留在子题上，单元 `options` 留空。
- 子题 `stem` 不重复材料里已有的标号，写 `______` 或 `31.`，不能写空串。

## 表格

表格按原卷网格还原，行列与合并关系都要留：

- 行列数照原卷写，不为了排版"多塞一格"。
- `colspan` / `rowspan` 取值 1–8，整张表必须是矩形。
- 表头行、合并单元格、跨整行的标题格都保留。
- 表格单元格里的插图写在 cell 内，用图片引用标记。
- 表格前后的正文单独放材料正文，不塞进表格。
- 材料里"表格前后都有正文"时，整篇按纯文本处理，不拆表格块。

## 必须排除

| 排除项 | 例子 |
| --- | --- |
| 卷名、年份页眉 | "××市 2025 年初中学业水平考试" |
| 考试时长、总分 | "满分 120 分，考试时间 90 分钟" |
| 整卷作答说明 | "本试卷共 8 页，答题前请…" |
| 扫码提示、答案册链接 | 二维码、"扫码练听力" |
| 装饰图、页眉 logo、分隔线 | 栏目条、水印 |
| 与本题组无关的相邻题 | 上一题遗留的选项行、下一题题号 |

排除项混进切片，是返工率最高的一类问题。`question_content.py` 用固定词表命中"考试时间 / 满分 N 分 / 本试卷共 / 扫码练听力 / 答案链接 / 初中学业水平考试"等字样，命中即报 `IRRELEVANT_HEADER`。

## 七项核对

`structure.json` 是核对对象，`structure_checks.py` 的 `CHECKS` 有七个键：前六项是结构检查，第 7 项 `content_scope` 管逐题内容范围。

| # | 键 | 中文标签 | 判什么 |
| --- | --- | --- | --- |
| 1 | `content_complete` | 题目内容完整 | 每道题该有的题干、选项、空位都在，没有缺口 |
| 2 | `stem_matches` | 题干与题目匹配 | 题干和它下面的选项/空位属于同一题 |
| 3 | `questions_options_complete` | 缺题漏题及选项完整 | 题号连续、无重复、无漏号；选项条数与标签完整 |
| 4 | `alignment` | 错行及上下题错位 | 没有串行、错位、上一题尾巴挂到下一题 |
| 5 | `images` | 图片完整且正确引用 | 正文引用的图片都存在，归属题号正确 |
| 6 | `grouping` | 按题型结构批次合并 | 该合组的合了，题号没有被重复归组 |
| 7 | `content_scope` | 逐题内容范围及媒体/表格完整 | 每道题只收本题内容；表格与图片归属正确 |

判定口径：

- 第 3 项：题号在结构中重复归属 → `failed`，原因「题号在结构中重复归属」。
- 第 6 项：题号被重复归入题组 → `failed`，原因「题号重复归属题组」。
- 第 7 项：含图片或表格、但没有与原件绑定的逐题视觉核对证据 → `unchecked`，原因「含图片或表格，缺少绑定原卷的逐题视觉核对证据」。
- 任一 `failed` 但没写原因 → 自动补「核对发现问题，需补充具体返工原因」。
- 整卷题号覆盖没有被人工核对 → 记一条问题「整卷题号覆盖未经绑定原卷和结构的人工核对，可能漏题」。

`structure.json` 的关键字段：

| 字段 | 含义 |
| --- | --- |
| `sections[].questions` | 该大题的题号，单个题号或 `[start, end]` 区间 |
| `sections[].type` | 该大题的题型 |
| `groups[].questions` | 题组成员题号 |
| `image_questions` | 图片题清单 |

## 切分顺序

按固定顺序切，前一步没定下来不要做下一步：

1. 按页和大题标题切出大题，记题号区间。
2. 在大题内按题号切出单元；题号跳跃处一定是边界。
3. 判定哪些单元是题组，把共享材料提到组级。
4. 逐题填字段：题干、选项、空位、答案、图片。
5. 排除卷头、说明、二维码、装饰图。
6. 把媒体清单、归属、正文标记位置逐项记下来。
7. 交人工做视觉核对，写核对人、区域、结论。

`structure.json` 的形状：

```json
{
  "sections": [
    {"title": "Ⅰ. 听力", "type": "听力短对话理解", "questions": [[1, 5]]},
    {"title": "Ⅱ. 阅读", "type": "阅读理解", "questions": [[31, 35]]}
  ],
  "groups": [{"questions": [16, 17]}],
  "image_questions": [26, 27]
}
```

`sections[].questions` 既可以是单个题号，也可以是 `[start, end]` 区间；题组写在 `groups[].questions`；图片题写在 `image_questions`。

## 证据绑定：unchecked 不等于 failed

每条核对结论都要绑定**三个哈希**，三者同时匹配才算 `bound`：

| 哈希 | 绑定对象 |
| --- | --- |
| `structure_sha256` | 当前 `structure.json` |
| `source_sha256` | 当前 `01_source/正文.txt` |
| `original_sha256` | 原卷文件 |

三条判定：

1. 哈希不匹配、缺核对人、缺证据 → `unchecked`，原因「缺少与当前输入哈希绑定的核对人或证据，或无法判断；需人工复核」。
2. `unchecked` 的处理方式是**补证或转人工**，不是"判错重做"。
3. `failed` 才表示"已确认有问题，需要返工"。

所以看到 `unchecked` 不要当成错误计数去清；要看成"这里还没人真正看过"。放行时 `unchecked` 和 `failed` 一样会挡住闸门，但两者的返工动作完全不同。

## 机器能查与只能人查

| 机器闸门能查 | 只能人查 |
| --- | --- |
| 题号重复、漏号 | 题号归属是否符合原卷语义 |
| 切片混入卷头或题组导语 | 图片是否被正确理解（图里有几道题、对应哪个选项） |
| 图片引用缺失 | 表格合并关系是否正确 |
| 表格标记不配对 | 题干与选项的语义是否匹配 |
| 候选题号、选项标签冲突 | 材料与小题的归属是否合理 |

机器闸门不能替代原卷视觉核对。结构确认人必须在审核记录里写清：核对人、页码/区域、结论（通过 / 有问题 / 不确定）。
