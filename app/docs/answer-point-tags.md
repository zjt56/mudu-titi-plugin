# 答案考点标签规则设计

凡当前机器维度表列有「答案考点」，且本题或本空的已核验答案是英文单词或短语，都追加一个同名知识点标签。原有词汇、语法、语音、体裁、主题等仍按各题型判定。

## 适用题型与保存层级

| 题型 | 标签保存位置 |
| --- | --- |
| 听力信息转换 | 按各空取词，按原题顺序去重后保存至题组，子题 `knowledge=[]` |
| 听力关键词语选择、单项填空、单词拼写 | 随实际考查的独立题或允许独立标注的子题保存 |
| 其他 | 该题有可定位的词或短语答案时，按当前标注层级保存 |

当前适用 5 类。短文填空、选词填空、教材语篇填空按材料保留语篇体裁、主题，按实际考点保留词汇、语法。完成句子按实际考点保留词汇、语法。

## 取词规则

1. 以答案填充阶段已验收的本题、本空答案为准，使用题目身份定位。选择题先把选项号解析到当前题或其所属题组的正确选项，再取选项中的单词或短语。例如答案 `B`、选项 `B. people`，标签为 `people`。
2. 填空保留实际作答词形和短语。答案 `people` 对应 `people`，`took care of` 对应 `took care of`。保留大小写、内部连字符和撇号，仅去掉外层排版标记及多余空白。
3. 多空按实际归属分别取词。有来源依据的多个可接受答案分别取词并去重；一个短语整体保留。分隔依据使用现有答案协议及来源绑定。整句、纯数字、缺失占位及无法映射到当前选项的答案跳过，并记录原因。

## 目录标注与工作台展示

- 工作台原标签在目录缺少答案考点节点时，从已完成且当前有效的 `answers` 产物、题型产物和最终批次题目现场派生显示。正式批次数据和目录知识点字段不写入未知路径。
- 上传预演对只读副本执行同一派生，并把答案考点路径合并到独立题或对应子题的 `knowledge`（官方正式容器路径为 `词汇/考察词汇/<词>`）。听力信息转换按题组汇总；答案目录 ID 由当前远端启用目录解析，稳定的原题数据与本地批次不改写。
- 在线 `prepare-upload`（`catalog=None`）时，若当前远端启用目录存在 `词汇/考察词汇` 容器但缺少本批次部分词条，插件自动以稳定 `Idempotency-Key` 调用 `POST /api/catalog/knowledge-points/ensure` 批量幂等注册（每批最多 200 条）并刷新目录快照，再将所得稳定 `id` 写入冻结副本的 `knowledge_ids` / `knowledge` / `knowledge_version_id`。
- 若上传 Key 未获授权注册（`403 knowledge_ensure_denied`）、词条停用（`knowledge_point_inactive`）或目录中无 `词汇/考察词汇` 容器，则明确阻断准备并提示联系主管理员开通父节点注册权限或走知识点提议流程，绝不静默跳过或把未知路径当成已批准标签。
- 派生以确认结构的题目身份逐题读取答案，并要求答案阶段验收答案与最终批次中的答案归一化一致。选择题还须唯一定位正确选项。填空按编号空位和可接受答案分隔拆分，保留词形、短语及原顺序后去重。句子、数字、占位、无法定位答案和选项歧义不显示为答案考点。
- 题型须在 `03_types/types.json` 的当前单元中含「答案考点」维度。题目、答案或题型产物缺失、过期或身份不唯一时不派生。审核对比使用旧输入摘要时，答案、题型和批次摘要都须与本次审核绑定一致。
- 线上公开开发者文档（2026-11-19 版）已在英语通用目录 1.1（522 节点）中内置 `词汇 / 考察词汇` 容器，并提供批量注册 `POST /api/catalog/knowledge-points/ensure`、AI 建议 `POST /api/catalog/knowledge-proposals` 及人工新增 `POST /api/catalog/knowledge-points` 接口。未知正式知识点会触发 `409 knowledge_confirmation_required`。[题库开发者文档](https://tiku.mudujiaoyu.com/developer.md)

答案词从已验收内容派生到工作台「原标签」显示的逻辑已实现并经真实批次核对。目录节点建设、稳定 ID 绑定及远端验收仍待认证目录复核。
