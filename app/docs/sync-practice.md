# 同步练习 / 课时同步材料的题型与组题判定口径

本文件说明 `app/references/sync-practice-rules.json` 与 `app/workflow/sync_practice.py`
的用途、边界和扩展方式。这套口径来自 26秋《课时A计划》英语 RJ **七上·八上·九上（学用）正文
854 处大题**的实测归纳，并经用户逐条看图确认。

课时卷的版式特征（每大题重排题号、并排小题、说话人前缀、图片小题、卷末紧跟答案区）与审核页题型直显要求，
见 [`sync-lesson-types.md`](sync-lesson-types.md)。

## 答案来源绑定与确定性补证

同步课时答案必须以 `section_id/unit_id/question_id` 和当前原文坐标证明归属，不能按全卷数字同号借用。正文锚点视图在剥除 HTML 和行尾空白前保留 `<u>空格</u>` / `<u>编号</u>` 的空位语义，例如 `A:Hello,Andy.1.<u>　</u>`；附录视图则保留真实数字答案和列间空白，不能把 `<u>5</u>` 当编号空位。

模型答案值与当前同题原文一致，但 evidence 只写了大题说明时，正常导入及分片验收可确定性补充真实坐标，保留候选答案值、原始响应及补证说明。补证仍复用严格的唯一绑定校验；跨大题同号、错误答案、歧义来源、无法绑定的 scope 均不得接受。只读校验不执行证据迁移。

完整答案已有唯一来源时使用 `answers_direct` 经正式 export/import 交付；局部修复只提交选定身份，未选基线仍须校验且逐字段保持原样。不是绕过局部范围或把未通过候选直接写入正式产物。

## 一、适用范围（重要）

只适用于**同步练习册 / 课时同步练习**类材料：

- 按课时编排（`Unit N` + 第 N 课时 + `Section A/B`）；
- 每课时常分**基础段**与**提升段**，提升段题号从 `Ⅰ` 重新开始；
- 典型大题：根据首字母及汉语提示补全单词、根据汉语意思完成句子、单项填空、完形填空、
  阅读理解、任务型阅读、补全对话、选词填空、短文填空、教材语篇回顾、语音题、书面表达。

**不适用**于单元卷、期中期末卷、月考卷、中考真题/模拟卷——这些材料的题型结构与组题
边界由原卷自身决定，不得套用本口径。

## 图片板块与正文/答案共同作用域（2026-11-12）

Word 正文中 `A 基础巩固` / `B 能力提升` 可能整条为图片；不能把答案区的同名文字当作正文已有标题。`lesson_bands` 读取当前原件、正文与独立图片引用，使用插件当前实际选定的 Harness 模型批量看图，保存 `01_source/lesson-bands.json`。每个边界含可见文字、原图片字节摘要与正文行范围；所有候选图片（含非横幅）均绑定摘要。宽高比/文件名只可作调度线索，不证明板块。

层级为单元→课时/专题→板块（若存在）→有号或无号大题→小题/编号空位→选项。各层按原件保留编号，不要求所有层必须从1起，也不为无号标题补造罗马号。Pronunciation 由实际标题上下文形成独立专题，不继承前一个 A/B。跨页跨栏不是结束条件；不改变 Word/OCR 原阅读顺序。

有效边界参与结构提示、窗口裁剪与 `source_section.lesson_band`，不改已有有效 `section_id/unit_id/question_ids`。独立草稿重建、原卷切片和最终payload消费同一来源。同行两列独立小题以 `source_span.start_offset/end_offset`（0基、右开，原始行字符）区分；预览不能回显相邻列当本题。

答案区独立识别自己的显式板块/专题，只有完整大题序列、归属与每节全小题覆盖一致才按原坐标展开紧凑答案；当前视觉已证明中段能力提升的无罗马号大题可以匹配同板块答案，不能仅按位置猜。错板块、错专题、残缺/矛盾标识、已存在却陈旧或有问题的视觉证据不回退旧数字匹配。多行答案引用所有实际源行；同scope同文重复可等价，跨scope同文仍不可借。

视觉图片语义按图片字节、路由和提示版本复用；板块位置始终按当前正文重建。模型切换即失效，失败短暂延期而非重复逐图请求。视觉不生成正文或答案，不代替真实覆盖验收。

Python→Node 视觉桥的 JSON stdin/stdout 固定为 UTF-8，不依赖 Windows 默认代码页或启动时的 `-X utf8`。仅 `route_identity` 成功不能证明中文图片路径可读；`lesson_bands.model_calls` 统计成功返回次数，不独立证明失败请求未发出。补齐历史失败的真实板块证据后，若旧确认结构仍把横幅收进前一题，应先用结构闸门按当前原文重新验证边界；不靠放宽答案 scope 或修改完成状态恢复。

## 二、判定内容

一次判定同时给出三件事，避免各批次各自解释：

| 维度 | 取值 | 说明 |
|---|---|---|
| `type` | 27 个主类之一 | 见 `app/references/filter-framework.json` 的 `question_types` |
| `subtype` | 主类的子类 | 必须与目录叶子完全一致，否则不能上传 |
| `kind` | `group` / `standalone` | 共用语篇/对话/表格/方框/图片 → group；每小句独立成题 → standalone |

`unit_kind` 在**结构确认**阶段定死，后续阶段不得改写；本模块只提供判据。

## 三、组题 / 单独题口径（用户 2026-11-11 确认）

**记为 group（整题组）**

- 完形填空、阅读理解、任务型阅读、选词填空、短文填空、教材语篇填空、补全对话；
- 语音题整大题（辨音选择、音标选词、字母表补全、大小写判断、音素归类、歌谣归类）；
- 凡「根据下图 / 根据图片信息 / 图示 / 家谱 / 地图」类看图题；
- 看图补全句子（「根据图片提示完成下列句子」「家谱/地图/图示完成句子」）→ `完成句子/补全句子`；
- 「四线三格写单词」「填词游戏」「根据音标从方框中选择」等共用格子/方框的题；
- 短文后完成思维导图 → `任务型阅读/阅读综合`；
- 「用 can/can't/could/couldn't 的适当形式填空」→ `选词填空/多句`；
- 「填入恰当的特殊疑问词或词组，完成对话」。

**记为 standalone（单独题）**

- 单项填空、完成句子（汉语提示 / 改写句子 / 划线提问 / 同义句转化）、单词拼写（汉语及首字母 /
  适当形式 / 汉语提示 / 词形转换 / 句意及音标中的一句一空题）、翻译、改错、书面表达；
- 一句一空的语法功能词填空（人称代词、do/does、连词 and/but/because、介词、How/What、if/whether、
  关系代词）→ `选词填空/多句`，仍按单独题；用户若统一改为组题，只改 `spell-grammar-word` 一条规则。

## 四、版块容器（不单独计数）

| 名称 | 处理 |
|---|---|
| `综合阅读提升` | 版块容器；其后的 `Ⅰ.完形填空`、`Ⅱ.阅读理解` 各自成题 |
| `单元话题写作` | 版块容器；内部通常含 1 道译写小题 + 2 篇书面表达（第一篇带审文导写） |
| `☆拓展设问` | 附在最后一小题后的开放性追问；并入所属组题的第 N 小题，不另立题型、**不计入空数** |

## 五、在代码里怎么用

```python
from workflow import sync_practice

sync_practice.classify("Ⅰ.根据首字母及汉语提示补全单词")
# {'type': '单词拼写', 'subtype': '汉语及首字母', 'kind': 'standalone', ...}

sync_practice.classify_with_body("Ⅳ.阅读理解", body)   # 用正文补 选择3题/4题/5题
sync_practice.audit_units(units, raw_text)             # 结构单元与口径对一遍，只报差异
sync_practice.prompt_block()                           # 给模型看的紧凑版口径
```

命令行自检与单条查询：

```bash
PYTHONPATH=app python3 -m workflow.sync_practice                # 校验规则是否合法
PYTHONPATH=app python3 -m workflow.sync_practice "Ⅱ.完形填空"   # 单条映射
```

## 六、在流程里落到哪

1. **提取与结构候选**：按原生行号识别课时、带序号及无序号作答标题，每处保留 `occurrence`、`start_line/end_line` 和课时上下文。同步材料中基础段/提升段重复大题号不再被误判为答案附录；中段范文不截断后续课时，明确的尾部答案块仍可分离。Markdown 加粗只在识别副本中清理，原文不改。
2. **结构确认（`structure_ai.auto_classify`）**：只在同步材料中追加完整规则条件和大题位置候选；归类完成后按标题归属比对题型、组单及共享材料窗口缺口，差异写入 `01_source/structure.ai.classified.json` 的 `sync_audit`。缓存绑定规则及识别模块摘要，规则变化后不复用旧结论。
3. **前置组装判型**：`preassemble` 使用的题型任务也接收同一规则与标题候选，任务输入摘要绑定规则文件和识别模块。题内的期中/月考等来源标签不能否定同步课时身份。
4. **不影响闸门**：`sync_audit` 只是留痕与提示，结构闸门仍以原卷证据为准；不因口径差异自动改题型、组/单或放行。
5. **题型/子类**：`classify()` 是标题映射，`classify_with_body()` 只在正文证据充分时补子类；例如只有 A–G 七个选项齐全才提示 7选5，任务型没有明确作答证据时不默认阅读问答。

### 单课时来源

后续按一个课时一批次录入。`metadata_ai.identify_source()` 从原件文件名、真实来源路径和独立章节标题识别 `grade/book/textbook_version/series/unit/lesson/section`，生成来源，例如 **七上人教版课时A计划 Unit 1 课时1**。`uint` 规范为 `Unit`，`Starter Unit 1` 与 `Unit 1` 分开。字段证据写在 `source_evidence`，有效非空的既有值保留。

原件名优先读取上传入口保存的原名，不使用批次名猜来源。真实父路径中明确的《课时A计划》可补系列证据；路径已丢失且文件名没有该系列时留空。整册含多个单元/课时，仅生成册级来源（例如“七上人教版课时A计划”），不拿第一课时冒充整册。没有模型配置时也可补齐确定证据字段，不改变阶段完成状态。

### 同课时重复题号与原卷排序

同步练习新结构采用 `identity_version=scoped-v1`。原卷大题的 `Ⅰ、Ⅱ、Ⅲ`、标题、课时上下文、出现序次和来源行号保存在 `source_section`，原样按源顺序展示；基础段与提升段再次出现的 `Ⅰ` 是不同大题。`numbers` 和子题 `number` 保留印刷小题号，不改成全课时连续编号。

`section_id` 标识大题，`unit_id` 标识一道独立题或一个题组，`question_ids[str(number)]` 标识其子题。答案、缺失决策、难度和证据的平面映射使用唯一 question ID；解析、知识点、审核与局部修正使用 unit ID 加本单元原号。ID 由来源位置生成，不取答案或题型；相同来源下调整题型、窗口或组单不会重写子题身份。A/B 两篇各有第1题时，以材料窗口区分；同一窗口真的重复、漏题、跨材料或身份混用仍阻断。

图片整题没有印刷小题号时明确保存 `source_span.number_binding=unnumbered_section`、`printed_numbers=[]`；`numbers=[1]` 只为旧字段契约的内部别名，不显示为原卷第1题。同行多题及 `C:1.` 形式仅在已绑定同步窗口中识别，原文不改。

来源材料必须证明同一大题、出现序次及局部原文坐标。纯数字答案附录没有大题对应证据时，明确报告来源尚未绑定，不选首条、不借同号答案，也不把真实存在但未绑定的内容当作缺失。保留 Word > PDF > 缺失占位顺序；作文不要求客观题答案。预览、编辑保存和原文审计均按唯一身份查找，不能回退到全文第一个同号题。

单课时紧凑答案可以通过完整大题序列绑定：正文与附录的全部 Roman 大题必须逐项同序；若正文只有末尾一节无 Roman，附录须在完整 Roman 答案之后明确出现唯一「能力提升」，且其后只有一块与该末节印刷题号逐项相等、无重复的答案。全部前序印刷题号也须完整覆盖；缺段、错课时、重复课时、错标题、未知续文、重复板块、多个无号大题或题号错位均不走此路径。原图板块标识不冒充 OCR 文字证据。

`unnumbered_section` 的 group 使用整节答案：字母歌的 `Ⅱ.C;G;…` 保留整串；图片填词的 `Ⅲ.1.VR … 6.CHINA` 保留完整编号串到内部别名，不新增或冒充印刷小题。引用须覆盖聚合答案的每一条实际源行；不接受只取首项、截断内容或借同文跨大题的坐标。当前无号字母串仅支持分号分隔的单个英文字母，其它未绑定写法如实拒收，不能记作缺失。确定性直抄仍由通用任务导出/导入与消费者校验交付，不调用模型、不直接改状态。

旧批次没有 `scoped-v1` 时继续旧数字协议，不迁移历史数据。结构失败的旧 provisional 数字兜底不接管 scoped 批次，避免串号。原件回归可定位七上全部305处大题；首课时118行通过结构→草稿→最终原文审计：27个单元、40个印刷小题号和1个无印刷题号内部别名。该确定性回归不替代后续真实模型打标、听力与内容审核。

## 七、扩展方式

新增或修正一条口径：先在 `sync-practice-rules.json` 的 `rules` 里加/改规则（`any` 关键词、
`none` 排除、`subtype_any` 附加条件、`type/subtype/kind`、`note` 写明依据），再跑
`python3 -m workflow.sync_practice` 自检（会校验主类与子类是否属于目录叶子），最后补一条
`app/workflow/test_sync_practice.py` 的用例。

规则顺序即优先级：更具体的规则必须排在更宽泛的规则前面（例如「完成思维导图」必须排在
「任务型阅读」之前，「填词游戏」必须排在「根据首字母…」之前）。

- 书面表达的子类（列中文要点 / 列思维导图 / 表格 / 图文结合…）由提示形式决定，规则里保持
  `subtype: null`，必须看正文后续内容才能定，不得按标题猜。

## 九、课时拆分件与提示标记（2026-11-11 对齐 Mudu-English-Upload）

课时拆分件（一份 docx＝一个课时）与合订练习册走同一套识别：课时标题形态不固定，版块标题与课时平级，
原卷提示标记属于原文的一部分。

### 课时 / 版块标题形态

- 课时标题认 `第一课时`、`第1课时`、`第1节课`、`课时1`、`Period 1`、`Lesson 1`；
  标题后可直接跟 `Section A (1a-2d)`（允许没有空格）或全角空格，不能要求必须有空白。
- `Reading Plus`、`Project`、`Reflecting`、`Pronunciation`、`综合阅读提升`、`单元话题写作` 与课时平级：
  只能作为课时上下文，不能当成大题标题，也不能并进上一大题的共享材料（窗口在它们之前结束）。
- 卷头出现「单元测试 / 期中 / 期末 / 月考 / 模拟」且后接「试题/试卷/测试/检测/卷」时，
  即使正文出现课时字样也不按同步练习处理，避免把复习卷套用本口径。

### 原卷提示标记必须留在题干或材料里

`[2025·六安月考]`、`[2023·安徽]`、`[新考法·跨学科]`、`[情境题]`、`[改编]`，以及无年份的
`[传统文化]`、`[安徽人文]`、`[榜样人物]`、`[经典谚语]`、`[熟词生义]` 都是原卷原文。比较完整括号及内容，
不能只靠同一年份或任一地区词判保留；`IMG/TABLE/答案/解析/参考答案` 等标签不是题目提示标记。

逐题标记留在所属题或子题题干，大题标题上的公共标记进入所属题组的作答指令；完形/填空句内的标记可留在原材料。
不得移到其他题、只放解析或只存 `source_section.title` 等元数据。成品 `subquestions` 与结构 `children`、选项和表格文本均纳入实际交付字段核对。落地分两层：

1. **结构阶段留痕**：`sync_practice.source_marks()` 与 `audit_source_marks()` 共用识别口径，
   缺失写入 `01_source/structure.ai.classified.json` 的 `sync_marks`，只提示、不改题干、不改结构闸门。
   `prompt_block()` 同步完整标记与所属题规则。
2. **上传前体检**：`app/scripts/06-upload/audit_source_marks.py` 复用 `audit_batch_source_marks()`。
   仅同步 `scoped-v1` 有真实标题坐标、匹配的章节终点/上下文/出现序次、题号身份和唯一来源窗口时检查本单元/本子题归属；
   显式窗口只信任 `ai_classified/cleaned_source`，过期章节或不可信窗口走保守检查。完形材料内标记与印刷选项块的子题标记分开归属。普通成品没有 `source_span` 时，
   仅在同一大题内题号唯一且组题材料窗口无歧义时重建。A/B 同号或跨材料边界不唯一时不猜。
   旧协议及无可靠 scope 的批次只保守检查整批完整标记是否存在，不以任意 token 假通过，不迁移或改写历史批次。
   检查只读，不触发上传、模型或真实批次重写。

### 课时编排自检（2026-11-11 第二轮对齐）

`sync_practice.audit_lesson_shape(raw_text)` 只看原卷坐标，检查三件课时级错误，结果写入
`extract.infer_structure()` 的 `structure.sync_practice.lesson_audit`（提取报告可见），不进入闸门、不改结构：

| 代码 | 判据 | 为什么必须报 |
|---|---|---|
| `LESSON_UNIT_MISSING` | 课时标题之前没有 `Unit N` 标题 | 单课时来源需要单元名；缺了就不得沿用上一单元或从批次名猜 |
| `LESSON_EMPTY` | 课时标题与下一个课时/答案区之间没有任何大题标题 | 空课时会整块丢题，不能静默跳过 |
| `LESSON_NUMBER_GAP` | 同一单元内课时序号不连续（第一→第三） | 跳号说明有课时没被切出来，须给出具体课时名与行号 |

课时序号支持 `第一课时`、`第1节课`、`课时3`、`Period 2`、`Lesson 4`（中文数字含 `十二`、`二十一`）。
真实七上正文复验：47 个课时标题、305 处大题、`lesson_audit=[]`；课时拆分件单课时文档同样为 `[]`。

`sync-practice-rules.json` 的 `lesson_constraints` 是课时录入约束的唯一文字来源，同时用于：
`prompt_block()` 的提示词条目（每个课时必须有单元名/至少一个大题/序号连续；版块与课时平级；材料带齐题号时不再重复生成同号子题；单元话题写作第1步词汇积累/思维导图不是题）。新增约束只改这份数组并补
`app/workflow/test_sync_lesson_shape.py` 用例，不另写一份提示词，避免提示词与自检各说一套。
