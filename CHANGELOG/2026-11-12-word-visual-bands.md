# 2026-11-12 Word 图片板块与答案归属贯通

## 背景

用户要求直接落地 Word 原生内容提取配合视觉理解，兼顾速度、质量、准确性，并解决答案与题目匹配。真实课时正文的 A基础巩固/B能力提升是图片；答案区有同名文字，不能误以为正文已有可匹配文字。

## 实现

- 新 `workflow/lesson_bands.py`：原生独立图片候选一次最多8图，由用户已选 Harness 模型判断真实图片内容；宽高比和文件名不作为分类真相。`01_source/lesson-bands.json` 保存原件/正文/全部候选媒体摘要、图片可见字、模型与源行边界。附录不能反推正文缺失板块。证据不改写正文或原题号。
- 标题边界通过 `structure_ai` 提示及缓存、`structure_gate` 窗口、`question_identity.source_section.lesson_band`、`question_draft` 独立复建贯通。单元有效 ID 不因增加板块前缀而改写。图片横幅不并入前题材料；Pronunciation 等真实专题结束前一个板块。
- `runner` 在提取后及结构前建立边界证据；三项视觉能力独立异常处理。`manifest` 按板块有效语义失效，耗时/调用计数不导致空转。
- `visual_transport`/`wf-vision` 使用实际安装的 pi-ai 提供商适配器，严格遵循当前插件 provider/model；不静默退到旧 magpie。通用 `visual_review` 同样批量、摘要去重、同路由缓存，复用已验证横幅，失败停止串行调用。
- 板块图按字节+路由+提示版本缓存；位置每次从当前正文重建。失败输入短暂延期60秒，避免 extract/structure 紧邻重复请求，不假报成功。
- 答案读取同源已验证板块，完整课时/专题/大题骨架和全部真实小题覆盖一致才匹配。紧凑多行保留完整坐标；错板块、错专题、陈旧证据、缺号不借答案。见专用答案变更记录。
- 实测补全对话 `N.<u>空格</u>` 和说话人行 `N.[IMG]` 在共用弱锚点定位，正文五空不再漏。同行双列印刷题号使用 raw line 字符窗，不把 Class 2.等正文数值当题号；音标紧贴 A.的四选项不遗漏。预览与草稿同字符窗。
- `structure_ai` 缓存包含实际路由，不沿用切换模型之前的拒绝候选；保留同输入候选本地复验能力。

## 边界

原件只读，Word 正文为文字权威。视觉只给结构/图片语义，不生成答案/解析。不改用户真实批次或manifest造通过，不自动上传/发布。此次真实验证使用独立临时提取目录，无旧批次/音频缓存复用。尚未声称整册全部版面或全部历史批次已完成内容审核；本轮解决的是 Word 图片板块、来源作用域、编号和消费链路。
