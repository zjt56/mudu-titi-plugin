# 用近期实卷减少答案与知识点模型工作

## 背景

回看安徽中考英语 2014、2015、2016、2017、2018、2020、2022、2023 八个本地批次的阶段时间、原生回执及候选。常规完成批次中，前置组装约 3–5 分钟，分轮审核约 4–6 分钟。知识点在多份卷达到约 5–8 分钟；2014 卷的两个原生知识点分片耗尽工具额度，主要花在目录、来源和逐单元查询。候选及各段耗时属于当时的代码、模型和调度条件，不能直接相加预测新卷耗时。

## 改了什么

- `upload_content.py` 的共用大题标题识别补上「关键词语选择」。正文、附录还要对上同一个大题编号和栏目名称，原题号、坐标、来源、冲突及整批验收仍照旧。修复前单个未识别标题使这五份卷的旧协议直抄整卷退出。
- `content_agent.py` 的知识点任务在独立字符上限内预载绑定目录和完整题目证据。目录过大时保留整个目录的工具访问。单元证据复用和 `read_unit` 相同的投影，超限单元仍走原工具。额度不变，耗尽后的复验保留、拆小和继续机制照常运行。
- `native-timing.json` 增记各工具动作计数，供后续按实际调用和排队耗时对比。

相关 Python 回归共 232 项，231 项通过、1 项跳过。包括不同大题标题拒绝直抄、冲突单元单独派发、知识点目录与单元证据超限时的工具访问、工具动作计数、持久回执恢复和分片拆小。2014 卷既有审核执行和格式检查均已完成，28 项差异保留待判断。

## 回退

撤回本次共用标题识别与知识点提示投影、计时计数及对应测试。历史试卷与既有验收回执无需调整。
