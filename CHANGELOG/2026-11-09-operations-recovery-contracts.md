# 运维恢复契约修复：发布、回滚、重启复验及局部生成

## 背景

用户在远端评估后要求“继续”。本轮落实前次评估发现的恢复链路问题，保持安装开关、明确确认、原失败检查复验与本地上传边界。基线包含另一会话独立完成的进度显示提交 e934a85；未将其界面改动混入本轮修复。

## 改了什么

- 宿主和后端统一使用源码根目录的发布标记，支持真实生产者的 ISO 日期及兼容秒/毫秒时间戳。过期、非法和未来 prepared 标记不会永久暂停监听；卸载插件时停止协调器和后续动作。
- Host 回滚要求可信 expectedRoot，只接受自动安装同样的 Python 模块允许清单及控制文件禁改清单。全部目标、备份、摘要、路径和符号链接在写入前检查；先暂存整批旧文件，再以原子重命名替换。普通替换或 journal 写入失败时恢复安装后文件；补偿失败如实报告，不声称安全恢复。拒绝根目录外、链接、缺失/损坏备份及被再次修改的目标。
- Python 安装/回滚同样检查路径和整批候选摘要，使用随机且独占创建的临时文件，避免预设临时文件链接。安装只回滚实际替换项；回滚检查全部备份，journal 写入失败也恢复安装后文件。
- 运维认领与安装绑定进程 PID 和世代。模块重载不算重启；真正更换进程并重新认领才允许复验，旧尝试失效。安装后失败的复验结清旧记录，新请求按当前源码捕获新工作区，保留历史并继续执行安装总预算。
- 重生成记录在真实执行结束后结清为成功/失败，未完成仍是排队状态；失败后相同证据会升级，不再永久 already_scheduled。部分写入出现异常保留 unknown 回执，不鼓励重复执行未知修改。
- 新增 [scoped_regeneration.py](../app/workflow/scoped_regeneration.py)：答案、解析、题型、知识点、听力映射共享模型输出范围与导入合并契约。只向模型发出选中单元的任务，拒绝多余单元，保留精确摘要绑定的其它产物并校验完整覆盖；未选中基线缺失/无效时拒绝扩大为整卷重跑。解析直抄和听力整图快路不能绕过显式局部修复。CLI、自动调度及通用文件导入使用同一契约。
- 修复本地代理错误包装覆盖 context_changed 原因的问题；旧分片测试显式启用 label_split，以便真正测试其宣称的分片路径，不更改生产默认配置。

## 没改什么与回退

未更改模型路由、审核范围、上传授权或自动安装开关；未安装/重启当前插件，未修改真实批次。听力局部修复仍引用具有有效切段证据的已有文件，不声称模型能修复音频边界或生成真实切片。普通 I/O 失败的补偿事务不等于多文件替换在进程强杀、断电时具备原子性。

需要回退时回退本轮提交即可；新增状态和历史字段不宣称旧版本能继续进行待重启安装，应先按实际 journal 与原始检查核对，不通过台账伪造成功。
