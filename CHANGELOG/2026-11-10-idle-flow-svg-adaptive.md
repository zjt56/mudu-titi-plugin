# 2026-11-10 无任务流程图全量展示 + 自绘 SVG 节点/连线 + 自适应宽度

## 背景

用户要求：即使没有任务，流程图也要全量展示（只是不显示工作状态），方便对外演示。随后要求把流程图高度做高（原按宽等比缩放，行距偏紧显得拥挤），用 SVG 自绘节点并画出已完成/未运行/运行中三态、运行中保留闪烁，且整套样式自适应宽度，随页面变化。

## 修改

- `lib/client.js`
  - `compactFlowStages(sourceItems, overview)` 增加 overview 分支：无任务时只按固定十二类与依赖生成中性结构，不构造任何批次/执行状态。
  - 右侧流程图不再用 `flowDone`（“暂无流程/本轮流程已结束”）整块替换；无论有无任务都渲染同一张十二类依赖图。无任务时隐藏进度条、计数、状态文字、动效与“继续处理”按钮，标题改为“流程总览”；进度/错误行仅在真实进度或读取失败时显示。
  - 布局加高：`R=13, ROW_H=108, PADY=30` 等，节点名两行更舒展，避免纵向拥挤。
  - 节点自绘三态：已完成=浅灰实底+灰勾；未运行=空心浅描边；运行中=脉冲外圈+呼吸圆点闪烁；失败/差异=彩色描边+“!”。新增 `--wf-flow-node-*` 主题 token（随浅/深色主题）。
  - 连线三态：已走过中性实线、流向运行中节点流动虚线（`wf-flow-dash` 沿路径偏移）、未走浅色虚线；箭头改为同线色填充分割三角形。
  - 自适应：`<svg viewBox>` 不设固定宽高，`width:100%; height:auto; aspectRatio=viewBox; preserveAspectRatio="xMidYMid meet"`，随列宽等比，外层空间不足时滚动兜底。
- 效果图：`artifacts/flow-node-states.svg`（含节点三态与连线三态，可打开看动画）。

## 边界

- 只调整上传页右侧流程图展示与样式，不改变十二类分类、真实依赖、阶段顺序或后端执行。
- 无任务时是“纯结构演示态”，不伪造任何完成/运行状态；有任务时完全恢复真实状态与进度。
- 节点状态数据仍来自后端 stage_cards/substeps；未放宽来源、审核、上传边界。
