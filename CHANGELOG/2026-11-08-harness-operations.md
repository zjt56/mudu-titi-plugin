# 2026-11-08 新增 Harness 批次运维辅助

## 背景与用户目标

用户希望插件遇到复杂卡点时由 Harness AI 实际接手调查、修复、验证和续跑，并能看到处理过程；明确要求不改变现有功能。采用附加服务，不替换现有录题阶段、supervisor、自愈规则、审核或上传入口。

## 改了什么（实现范围）

- 新增 Python operations 事件台账、接手租约、幂等动作回执与受控修复工具接口。读取原文/报告及限定源码、真实预演、现有事务修复、消费者复验、交回正常队列续跑；绑定批次身份与接手尝试。
- 新增 Harness 原生会话管理器，使用受支持 agents.create/resume 接口及 scoped tools。已保存的会话复用身份；模型选择来自插件显式 operations/default 路由；禁止静默换模型。
- 独立运维开关及可选宿主服务挂载。服务不存在、配置异常或用户关闭时，原有录题与自愈保留。
- 排队区增加 AI 运维状态、最近动作、真实验证证据及会话标识复制，不新增流程阶段。
- 未知请求结果先查回执，不换request_id盲重发。模型空闲或自述成功不等于修复成功；模型处理有动作与时间预算。

## 边界

运维会话没有通用shell或任意批次写入权限，不修改运行中的插件源码，不伪造阶段完成，不上传或发布。未知程序缺陷记录为需深入修复并保存复现证据；并非所有未知故障均能自动解决。
