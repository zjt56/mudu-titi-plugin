# 任务型阅读文章大意与解析排版修复

## 背景
用户截图中 2023 年安徽卷 73–75 题的长答案挤压解析：73 题解析变为窄列，75 题答案超宽被裁切。根因是题号、禁止收缩的答案与解析共用一条 flex 行。

## 修改
- lib/client.js：逐题行改为题号 + minmax(0,1fr) 正文两列，正文内答案和解析上下排列；长答案保留完整文本并允许无空格换行。
- 有解析与展开后的缺失解析行共用 renderRow，避免缺失行保留旧布局；独立题标题中的答案同样约束宽度。
- backend/review-content-preview.test.cjs：增加真实组件结构测试，覆盖长英文答案、无空格长串、完整解析与缺失提示。

## 边界
只改展示，没有读取/重写试卷批次、重跑流程、裁决差异或上传。既有折叠、空态、无号题语义不变。保留工作区其它未提交改动；apply_patch 在环境中不存在，因此采用工具定点编辑。

## 验证
- 预览测试 12/12 通过。
- node --test --test-reporter=dot backend/*.test.cjs backend/*.test.mjs 全量退出码 0；node --check lib/index.js 与 lib/client.js 通过。
- 浏览器独立样例（提取当前组件与 CSS，轻量 React facade）：300px/560px 内容栏 7 个批次步骤全部通过，包括答案与正文无横溢出、解析位于答案下方、全部展开/收起、缺失行展开。样例不代表真实宿主页已刷新验证。
- Impeccable 布局扫描无发现；git diff --check 通过。
