# 2026-11-09 本机上传设置

## 背景
用户要求按受控运维说明配置当前插件上传设置，并指定本机私钥文件。

## 改了什么
通过运行中插件的设置接口保存 API 本机回环地址、英语科目、上传账号、登录密码与 SSH 参数。实际值与凭据仅保存在仓库外的宿主私有状态目录，不写入本文或任务包。按用户指定切换私钥；修正该文件过宽的 Windows ACL。将凭据目录及文件的 ACL 限定为当前用户，避免 Windows 上 POSIX mode 无法限制继承权限的问题。使用 UTF-8 请求字节保存中文路径并核对回读。

## 边界
无代码修改，无题目上传、确认、发布、账号恢复或权限变更。API Key 尚未提供，因此未执行带认证的目录读取；保存密码不代表远端账号已恢复或登录成功。临时验证隧道检查后关闭，后续由既有上传流程按需建立。

## 验证
4 项通过：指定密钥 SSH 认证；回环隧道 API health 返回 ok=true；监听地址仅 127.0.0.1；插件配置回读成功且中文路径精确匹配。密码文件 ACL 仅一条当前用户许可。无代码改动，未运行代码回归测试。

## 回退
在插件上传设置中修改非敏感参数或清除登录密码；不要将凭据复制到版本控制。SSH 私钥权限保持当前用户独占。
