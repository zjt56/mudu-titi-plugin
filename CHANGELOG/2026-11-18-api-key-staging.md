- `app/workflow/upload.py`：保留冻结与批准绑定；先保存暂存 ID，再追加附件。未知创建仅允许使用原 Key、原目标和原冻结请求显式恢复，冲突和无法证明身份的旧记录不重发。
- 工作台允许新版绑定记录显式恢复，更新上传设置提示。未改题号、目录、来源校验及用户批次，不自动确认、生成草稿或发布。
