# 2026-11-07 建立 AGENTS.md 与 CHANGELOG 制度

## 背景 / 触发
用户要求：「在该项目的创建 agents 文件，同时也要创建一个文件夹，专门记录项目变更的。要添加一个规则，
就是每次有重大改动都要给它记录下来，然后有强调、反复强调的规则也要给它记录下来……有重大的项目变更，
也要给它记录下来。」

此前项目只有 `app/AGENTS.md`（工作流任务协议细节），没有面向所有 Agent 的根目录总入口，也没有统一的变更/规则台账。

## 改了什么
- 新增根目录 `AGENTS.md`：项目地图、10 条硬规则、变更记录制度、验证要求、协作提示。
- 新增 `CHANGELOG/`：
  - `README.md`：记录制度 + 变更索引。
  - `RULES.md`：规则/强调台账（逐条含日期、原话要点、落地位置）。
  - `2026-11-07-*.md`：每次重大改动一份记录。
- `AGENTS.md` 第二节硬规则与 `CHANGELOG/RULES.md` 互相同步；新增/修订规则时两处都要写。

## 没改什么 / 边界
- 未改动任何工作流代码、模型路由或提示词行为；纯文档与制度。
- `app/AGENTS.md` 保持原样作为任务协议细节，根目录 `AGENTS.md` 作为总入口指向它。

## 如何验证
- 文件已创建：`AGENTS.md`、`CHANGELOG/README.md`、`CHANGELOG/RULES.md`。
- 未触及代码，无需跑测试；下一次行为类改动会按本制度留痕。

## 回退方式
删除 `AGENTS.md` 与 `CHANGELOG/` 即可，无副作用。
