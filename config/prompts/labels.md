# 一审（labels）自定义指令

在插件设置页可编辑。留空则使用工作流内置的默认一审指令（不覆盖）。

一审为全量盲判：不参考任何现成标签，只按原卷题干、材料、选项、答案与解析，独立判断主类、子类、组级知识点以及本单元每道小题的难度（容易/适中/困难）；在 rationale 说明依据。整组题型只判组级知识点、其子题 knowledge=[]，不逐小题打标签；独立单题判自身知识点。知识点路径必须逐字取自供给目录，不得自造更深子级；整篇类题型只判组级知识点、其子题 knowledge=[]。答案、解析与文章大意的冲突用 verdict=error|uncertain 加 rationale/evidence 指出，不得编造。
