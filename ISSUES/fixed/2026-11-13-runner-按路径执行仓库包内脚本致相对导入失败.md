## 现象（卡点）

原卷提取失败：attempted relative import with no known parent package

## 具体检查与判定

- 失败检查：EXTRACT_COMMAND_EXIT_1
- 判定口径：runner._execute_command_stage 对以 .py 结尾的命令一律 sys.executable+脚本路径、cwd=app，运行 app/workflow/extract.py 时 sys.path[0]=app/workflow，绝对导入 from workflow import manifest 无法解析父包，任何新批次 extract 都确定性失败
- 修复方向：改为把 app/workflow 下的包内脚本以 -m 模块方式执行（python -m workflow.extract），app/scripts 下无父包脚本保持路径执行；补 test_runner_auto::test_repo_package_script_runs_as_module_not_by_path

## 修复记录

- 修复方式：runner 新增 _stage_argv，把 app/ 下包内脚本以 -m 模块执行，standalone 脚本保路径执行
